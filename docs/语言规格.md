# 基石语言规格（v1.0）

> 本文件是基石语言的**正式语言规格**，描述当前已实现的全部语法、语义与
> 标准库 API 边界。自 v1.0 起，语法/语义/标准库 API 冻结：后续改动须在
> `docs/设计决策.md` 补充决策记录，并遵循语义化版本规则（主版本=不兼容变更，
> 次版本=新特性，修订=修 bug）。
>
> 历史版本：v0.2（M1 阶段）→ v1.0（M15 收敛，冻结于 M0–M14 全部特性）。

## 1. 文件与运行

- 源文件后缀：`.jsh`，UTF-8 编码
- 运行：`jishi 文件.jsh`；交互式：`jishi -i`
- 调试：`jishi 文件.jsh --ast` 查看语法树
- 编译为跨语言字节码：`jishi 文件.jsh --dump-bytecode`（M13）
- 执行字节码：`jishi 文件.json --load-bytecode`

## 2. 关键字

| 关键字 | 作用 |
|--------|------|
| `令` | 声明/赋值变量 |
| `如果` / `否则如果` / `否则` | 条件分支 |
| `遍历 … 在 …` | for 循环 |
| `循环 N 次` | 固定次数循环（`次` 可省略） |
| `当` | while 循环 |
| `中断` / `继续` | 跳出/跳过循环 |
| `函数` / `返回` | 定义函数 / 返回值 |
| `导入 模块名` | 导入基石标准库 |
| `真` / `假` / `空` | 布尔值与空值 |
| `与` / `或` / `非` | 逻辑运算 |
| `尝试` / `捕获 … 为 …` / `最终` | 异常处理 |
| `抛出` | 抛出异常 |
| `类` / `继承` / `新建` | 定义类 / 继承 / 创建实例 |

## 3. 标点与空白

- 全角标点（`：` `，` `（` `）` `＝` `＋` …）与半角标点等价，写作时无需切换输入法
- 行首缩进使用**半角空格**（推荐 4 格）；全角空格（U+3000）出现在缩进中会报错
- Tab 与空格混用会报错
- 字符串与注释内部不进行标点归一化

## 4. 注释

```python
# 单行注释

#- 多行
注释 -#
```

## 5. 标识符

- 支持中文、英文、数字、下划线混写：`分数`、`total_数量`、`_x`
- 不能以数字开头
- 关键字保留，不可作标识符；关键字后必须跟空白或符号分隔

## 6. 字面量

| 类型 | 示例 |
|------|------|
| 整数 | `42` |
| 小数 | `3.14`、`2e3`、`.5` |
| 文本 | `"你好"`、`'单引号'`、`“中文引号”`、`'''多行'''` |
| 布尔 | `真`、`假` |
| 空 | `空` |
| 列表 | `[1, 2, 3]`（支持尾随逗号 `[1, 2, 3,]`；括号内可跨行书写） |
| 字典 | `{"语文"：95}` |
| 插值文本（M7） | `` `你好 {名字}，今年 {年龄} 岁` `` |

插值文本用反引号 `` ` `` 包裹，`{表达式}` 内的内容会被求值并转成文本插入；
`{{` / `}}` 表示字面花括号：

```python
令 名字 = "小明"
令 年龄 = 18
打印(`你好 {名字}，今年 {年龄} 岁`)   # 你好 小明，今年 18 岁
打印(`{3} + {4} = {3 + 4}`)           # 3 + 4 = 7
```

## 7. 运算符

- 算术：`+` `-` `*` `/`（真除法）`//`（整除）`%`（取余）`**`（幂）；文本可用 `+` 拼接、`*` 重复
- 比较：`==` `!=` `<` `>` `<=` `>=`；支持**链式比较** `60 < 分数 <= 90`（中间表达式只求值一次，短路）
- 逻辑：`与` `或` `非`（短路求值）
- 赋值：`=` `+=` `-=` `*=` `/=` `//=` `%=` `**=`
- 成员访问：`模块.函数`、`对象.方法(...)`、`列表[下标]`、`字典[键]`

## 8. 语句

### 变量
```python
令 分数 = 60
分数 += 5          # 复合赋值
数据[0] = 100      # 下标赋值
```

### 切片（M18.1）
```python
令 a = [1, 2, 3, 4, 5]
a[1:3]        # [2, 3]     起:止
a[::-1]       # [5, 4, 3, 2, 1]   倒序
a[:2]         # [1, 2]     省略起
a[2:]         # [3, 4, 5]  省略止
a[::2]        # [1, 3, 5]  步长
a[:]          # [1, 2, 3, 4, 5]   全复制

"你好世界"[1:3]   # "好世"   字符串同样支持
```
- 起/止/步长分量都可省略（省略为「不指定」），也可用表达式（`a[i:j]`）
- 当前支持切片**读取**，不支持切片赋值（`a[1:3] = [...]`）

### 多赋值与解包（M7）
```python
令 a, b = [1, 2]        # 列表解包（数目须精确匹配）
a, b = b, a             # 交换两个变量
令 x, y = 计算坐标()     # 函数多值返回 → 解包

返回 1, 2               # 多值返回：等价于 返回 [1, 2]
```
- 解包右值限列表（含 Python 桥接的元组），数目不符会中文报错
- 多值返回「返回 a, b」编译为「返回 [a, b]」（基石多值即列表）

### 表达式语句
以值开头的行都是合法语句（REPL 中会回显结果，非空值时显示）：
```python
1 + 2          # 顶层表达式
"你好"
[1, 2] + [3]
```

### 条件
```python
如果 分数 >= 90：
    打印("优秀")
否则如果 分数 >= 60：
    打印("及格")
否则：
    打印("不及格")
```

### 循环
```python
遍历 分数 在 [85, 92, 78]：
    打印(分数)

循环 3 次：
    打印("你好")

当 分数 < 100：
    分数 += 1
```

### 推导式（M7）
```python
[x * 2 遍历 x 在 [1, 2, 3]]              # [2, 4, 6]
[x 遍历 x 在 [1, 2, 3, 4] 如果 x > 2]     # [3, 4]
{x: x * x 遍历 x 在 [1, 2, 3]}            # {1:1, 2:4, 3:9}
```
- 列表推导与字典推导均支持；`如果` 条件子句可选
- 循环变量与「遍历」语句一致（写入当前作用域）

### 函数
```python
函数 求和(a, b)：
    返回 a + b

打印(求和(3, 4))
```

### 默认参数（M7）
```python
函数 打招呼(名字, 语气 = "你好")：
    打印(语气, 名字)

打招呼("小明")          # 你好 小明
打招呼("小明", "欢迎")  # 欢迎 小明
```
- 默认值在定义处求值一次（与 Python 一致）
- 有默认值的参数必须排在最后

### 导入
```python
导入 随机                          # 基石标准库（中文 API）
令 n = 随机.随机整数(1, 100)

导入 math 从 python                 # Python 生态桥接（M3）
打印(math.sqrt(16))                 # 4.0

导入 math 从 python 为 数学          # 起别名
打印(数学.sqrt(9))                   # 3.0

导入 数学工具 从 本地包              # 本地包（M10.2）
打印(数学工具.平方(8))

导入 文本 为 t                      # 普通导入也支持别名（M18.4）
打印(t.计数("香蕉苹果", "香"))       # 1
```
- 标准库导入也支持 `为 别名`（M18.4），避免模块名遮蔽内建（如 `导入 文本`
  会遮蔽内建 `文本()`；用 `导入 文本 为 t` 可两全，导入时会打印一次中文提示）

Python 桥接规则（M3）：
- 导入的 Python 模块成员原样可用（函数、类、常量）；下划线开头的内部成员不可见
- Python 对象的公开属性/方法可直接访问：`datetime.datetime.now().year`
- 基石函数可以直接传给 Python 高阶函数（如 `builtins.map(基石函数, 列表)`）
- Python 侧抛出的异常自动翻译成中文错误（找不到文件、权限不足、递归过深…）

本地包规则（M10.2）：
- 包是 `.jishi/packages/名字/` 目录，含 `包.json`（名字/版本/依赖）与若干 `.jsh` 模块
- 执行所有模块后，顶层定义的函数/变量作为包成员导出
- 搜索顺序：项目目录 `.jishi/packages/` → 用户目录 `~/.jishi/packages/`

包清单 `包.json` 字段：

```json
{
  "名字": "某包",
  "版本": "1.0.0",
  "依赖": {"基础库": ">=1.0.0"},
  "描述": "可选说明"
}
```

- `依赖`：名字 → 版本约束。导入某包时会**先递归加载其依赖**，校验依赖版本
  满足约束后，把依赖包对象注入到该包模块的命名空间（模块里可直接 `依赖名.成员`，
  无需重复导入）。
- 版本约束语法：`*` 任意；`1.2.3` 精确；`>=1.0.0` / `<=2.0.0` / `>` / `<`；
  `^1.2.3` 主版本锁定（>=1.2.3 且 <2.0.0）。约束不满足报中文错误。
- 循环依赖（甲依赖乙、乙依赖甲）会报「检测到循环依赖：甲 → 乙 → 甲」。

远端索引格式（M10.2，先静态 JSON 文件托管，不建站）：

```json
{
  "格式": "jishi-package-index",
  "版本": 1,
  "包": {
    "某包": {
      "版本": "1.0.0",
      "下载地址": "https://例/某包-1.0.0.zip",
      "依赖": {"基础库": ">=1.0.0"},
      "描述": "……"
    }
  }
}
```

- `格式` 固定为 `jishi-package-index`，`版本` 为索引格式版本号（当前 1）。
- 校验逻辑在 `jishi/packages.py`（`parse_index` / `resolve_package` /
  `version_satisfies`），供 `jishi 安装` 命令（M14）复用。

包管理命令（M14.2）：

```bash
jishi 安装 包名 --local-dir 目录          # 从本地目录安装（含 包.json）
jishi 安装 包名 --local-zip 包.zip        # 从本地 zip 安装（内含 包名/ 顶层目录）
jishi 安装 包名 --from-index 索引.json     # 从远端索引拉包（本地文件或 URL）
jishi 安装 包名 --force                   # 覆盖已安装的同名包
jishi 卸载 包名                            # 卸载本地包
jishi 列表                                 # 列出已安装的包（名字/版本/描述）
```

- 安装目标：项目 `.jishi/packages/`（不存在时自动创建）；搜索顺序与导入一致
  （先项目后用户目录）。
- 从索引安装会「读索引 → 取下载地址 → 下载 zip → 解压安装」全自动完成。

### 关键字参数（M3）
```python
导入 json 从 python
打印(json.dumps({"姓名"： "小明"}, ensure_ascii=假))  # 中文不被转义

函数 介绍(姓名, 年龄)：
    返回 姓名 + "今年" + 文本(年龄) + "岁"
打印(介绍(姓名 = "小红", 年龄 = 8))     # 基石函数同样支持
打印(介绍("小刚", 年龄 = 20))           # 位置参数 + 关键字参数
```
规则：
- 调用中「名字 = 值」一律按关键字参数处理（调用内部没有赋值语义）
- 基石函数按参数名绑定；缺参数会明确指出缺哪个，多传/未知参数名会报错
- 布尔值写 `真`/`假`，空值写 `空`；从 Python 抄来 `True`/`False`/`None` 时，
  报错会提示对应的中文写法
- 第三方库（pandas 等）先在 Python 环境里 pip 安装，之后可直接导入

### 8.9 异常处理

```python
尝试:
    令 结果 = 整数("不是数字")
捕获 类型错误 为 e:
    打印("输入不对：", e.消息)
捕获 异常 为 e:            # 「异常」是所有错误的基类，抓得住一切
    打印("其他错误：", e.类型)
最终:
    打印("无论如何都会执行")
```

- `捕获` 可以有多个，从上往下匹配第一个符合的；`最终` 最多一个且可选。
- 捕获条件按**错误类型名**匹配，基类能抓子类：`异常` > `运行期错误` >
  `类型错误`/`值错误`/`索引错误`/`键错误`/`除零错误`/`文件错误`。
- 不写类型就是全抓：`捕获 为 e:`（或干脆 `捕获:`）。
- `抛出 表达式` 抛出任意值；非异常对象会被自动包成「异常」，原值留在 `e.消息`：

```python
函数 取折扣价(原价, 折扣):
    如果 折扣 <= 0 或 折扣 > 1:
        抛出 值错误("折扣必须在 0 到 1 之间")
    返回 原价 * 折扣
```

- 异常对象可读属性：`e.消息`（中文说明）、`e.类型`（如「值错误」）。
- 未被捕获的异常照常渲染成中文报错（含文件行列），程序终止。

### 8.10 类与继承

```python
类 动物:
    函数 初始化(自身, 名字):
        自身.名字 = 名字
    函数 叫(自身):
        打印(自身.名字, "在叫")

类 猫 继承 动物:
    函数 叫(自身):            # 覆盖基类方法
        打印(自身.名字, "喵喵")

令 咪咪 = 新建 猫("咪咪")
咪咪.叫()
```

- `类 名字:` 定义类；类体里只能写方法（`函数`），方法与普通函数写法一致。
- 方法第一个参数约定叫 `自身`（普通标识符，不是关键字），表示实例本身，
  调用 `实例.方法(...)` 时自动绑定。
- `初始化` 是约定俗成的构造方法，`新建 类(参数)` 时自动调用；
  没定义 `初始化` 则 `新建 类()` 造空实例，传参报错。
- `继承 基类` 让子类复用基类方法，子类同名方法覆盖；基类必须确实是类。
- 实例字段用 `自身.名字 = 值` 创建，`实例.字段` 读取；不同实例互不影响。
- 类型名：类显示为「类 名字」，实例显示为「名字 实例」。

## 9.5 对象方法（M1）

方法通过 `对象.方法(...)` 调用；列表与字典的方法为原地修改，文本方法返回新值。

| 对象 | 方法 |
|------|------|
| 列表 | `追加(v)` `插入(位置, v)` `移除(v)` `弹出(位置=-1)` `排序()` `反转()` `清空()` `索引(v)` `计数(v)` `包含(v)` |
| 字典 | `获取(键, 默认=空)` `键()` `值()` `包含(键)` `更新(字典)` `弹出(键, 默认=空)` `清空()` |

| `压缩` | 打包（文件或目录→zip）/ 解压 / 列出内容 |
| `系统` | 系统名 / 系统版本 / 机器架构 / 处理器 / 当前目录 / 改目录 / 环境变量 / 设环境变量 / 执行（外部命令）/ 退出码 / 主机名 / 参数（命令行参数，M18.2） |

> 命令行参数（M18.2）：`jishi 脚本.jsh 参数1 参数2` 中，脚本名之后的参数
> 传给脚本，脚本内 `系统.参数()` 返回这些参数组成的列表（不含脚本名）；
> 用 `--` 分隔可把 `--` 开头的内容也当脚本参数（`jishi 脚本.jsh -- --foo`）。
> 注意：`导入 文本` 后，内建转换函数 `文本(...)` 会被模块遮蔽，导入时会打印一次
> 中文提示；如需两全，用别名 `导入 文本 为 t`（M18.4）。
> 正则模式写 `"\d+"`（基石的未知转义会保留反斜杠，无需 r 前缀）。
> `路径`/`压缩` 涉及文件系统访问、`系统` 涉及执行外部命令，沙箱默认拦截
> （需显式开启 allow_write / allow_network）；`加密` 纯摘要计算，沙箱默认放行。

## 11. 中文报错

所有错误以中文呈现，带错误码、行列定位与修正建议：

```
错误 E0106：关键字与后面的内容粘连了（「如果分数」被当成了一个名字，但它的开头是关键字「如果」）
  ┌─ 文件.jsh:1:1
  │
1 │ 如果分数 > 60：
  │ ~^
  │
  提示：你是不是想写「如果 分数」？关键字和后面的内容之间要留空格
```

错误码分段：`E01xx` 词法、`E02xx` 语法、`E03xx` 语义、`E2xxx` 运行期。

### 11.0 调用栈回溯（M17）

运行期错误若发生在函数调用深处，报错下方会附带「调用链（从外到内）」，标明
每一层是「哪个函数」在「第几行」被调用：

```
错误 E2003：索引越界（list index out of range）
  ┌─ 脚本.jsh:3:9
  3 │     打印(x[10])
    │         ^
  │
调用链（从外到内）：
  外层 ← 第 8 行
  中层 ← 第 7 行
  里层 ← 第 5 行
```

- 递归超限（`RecursionError`）同样走中文翻译 + 调用链 + 「是不是忘了结束条件」建议；
- 协议/沙箱的 JSON 错误里也带 `trace` 字段（agent 可程序化读取）；
- 调用链最多显示最近 20 帧，避免深层递归刷屏。

### 11.1 容错解析（M7.5）

基石会识别「用英文写了 Python 关键字/内建」的常见错误（大模型写中文代码时
容易 fallback 回英文），并直接给出中文对应建议：

```python
def f(x):        # → 「def」是英文关键字，你是不是想写「函数」？
print(1)         # → 「print」是 Python 内建，基石里叫「打印」
令 x = True      # → 「True」是英文写法，你是不是想写「真」？
令 y = 1 and 2   # → 「and」是英文写法，你是不是想写「与」？
```

覆盖三类：英文语句关键字（def/if/for/while/return/import/class/try…）、
值/运算符关键字（True/False/None/and/or/not/in/is）、内建函数
（print/len/range/int/float/str/type/min/max/sum/reversed）。
英文普通变量名（`a`、`data` 等）不受影响。

## 12. 已知边界（v1.0 冻结时的诚实声明）

以下特性**当前不支持**，已诚实标注，留待后续版本评估：

1. **标准库返回原生 Python bool**：`路径.存在()` 等薄封装返回 Python 的
   `True`/`False`，打印显示为 `True`/`False`（非「真/假」），与 `日期.早于()`
   一致。这是 Python 桥接返回原生 bool 的既有显示路径。
2. **Rust 宿主为「最小可运行」**：`rust/` 的可变容器语义（`列表.追加` 反映回
   原变量）需 `Rc<RefCell>` 重构，当前未完整对齐（详见 docs/embed.md）。
3. **无切片赋值**：`列表[a:b]` 读取（切片）已支持（M18），但不支持
   `列表[a:b] = [...]` 切片赋值。

以上边界均属「已知、诚实标注、留待演进」，不影响 v1.0 的核心语言特性冻结。
