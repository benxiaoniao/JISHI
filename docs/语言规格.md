# 基石语言规格（v1.0）

> 本文件是基石语言的**正式语言规格**，描述当前已实现的全部语法、语义与
> 标准库 API 边界。自 v1.0 起，语法/语义/标准库 API 冻结：后续改动须在
> `docs/设计决策.md` 补充决策记录，并遵循语义化版本规则（主版本=不兼容变更，
> 次版本=新特性，修订=修 bug）。
>
> 历史版本：v0.2（M1 阶段）→ v1.0（M15 收敛，冻结于 M0–M14 全部特性）。

## 1. 文件与运行

- 源文件后缀：`.jsh`，UTF-8 编码
- 运行：`jishi 文件.jsh`；交互式：`jishi -i`
- 调试：`jishi 文件.jsh --ast` 查看语法树
- 编译为跨语言字节码：`jishi 文件.jsh --dump-bytecode`（M13）
- 执行字节码：`jishi 文件.json --load-bytecode`

## 2. 关键字

| 关键字 | 作用 |
|--------|------|
| `令` | 声明/赋值变量 |
| `如果` / `否则如果` / `否则` | 条件分支 |
| `遍历 … 在 …` | for 循环 |
| `循环 N 次` | 固定次数循环（`次` 可省略） |
| `当` | while 循环 |
| `中断` / `继续` | 跳出/跳过循环 |
| `函数` / `返回` | 定义函数 / 返回值 |
| `导入 模块名` | 导入基石标准库 |
| `真` / `假` / `空` | 布尔值与空值 |
| `与` / `或` / `非` | 逻辑运算 |
| `尝试` / `捕获 … 为 …` / `最终` | 异常处理 |
| `抛出` | 抛出异常 |
| `类` / `继承` / `新建` | 定义类 / 继承 / 创建实例 |
| `用 … 为 …` | 上下文管理器（M26.2），见 §7.12 |
| `匹配` / `情形` | 模式匹配（M34.1），见 §8.11 |
| `枚举` | 枚举（M34.2），见 §8.12 |

注：`匹配` / `枚举` 是**软前缀**——`匹配组`、`枚举值` 这些仍可作普通标识符
（见 §5 标识符）。另外 `.` 后面的**属性名允许是关键字**（M34 起），
所以 `正则.匹配(...)` 照常可用。

## 3. 标点与空白

- 全角标点（`：` `，` `（` `）` `＝` `＋` …）与半角标点等价，写作时无需切换输入法
- 行首缩进使用**半角空格**（推荐 4 格）；全角空格（U+3000）出现在缩进中会报错
- Tab 与空格混用会报错
- 字符串与注释内部不进行标点归一化

## 4. 注释

```python
# 单行注释

#- 多行
注释 -#
```

## 5. 标识符

- 支持中文、英文、数字、下划线混写：`分数`、`total_数量`、`_x`
- 不能以数字开头
- 关键字保留，不可作标识符；关键字后必须跟空白或符号分隔

## 6. 字面量

| 类型 | 示例 |
|------|------|
| 整数 | `42` |
| 小数 | `3.14`、`2e3`、`.5` |
| 文本 | `"你好"`、`'单引号'`、`“中文引号”`、`'''多行'''` |
| 布尔 | `真`、`假` |
| 空 | `空` |
| 列表 | `[1, 2, 3]`（支持尾随逗号 `[1, 2, 3,]`；括号内可跨行书写） |
| 字典 | `{"语文"：95}` |
| 插值文本（M7） | `` `你好 {名字}，今年 {年龄} 岁` `` |

插值文本用反引号 `` ` `` 包裹，`{表达式}` 内的内容会被求值并转成文本插入；
`{{` / `}}` 表示字面花括号：

```python
令 名字 = "小明"
令 年龄 = 18
打印(`你好 {名字}，今年 {年龄} 岁`)   # 你好 小明，今年 18 岁
打印(`{3} + {4} = {3 + 4}`)           # 3 + 4 = 7
```

## 7. 运算符

- 算术：`+` `-` `*` `/`（真除法）`//`（整除）`%`（取余）`**`（幂）；文本可用 `+` 拼接、`*` 重复
- 比较：`==` `!=` `<` `>` `<=` `>=`；支持**链式比较** `60 < 分数 <= 90`（中间表达式只求值一次，短路）
- 成员测试（M23）：`在` / `不在`——`名字 在 名单`、`9 不在 范围(5)`。
  可用于列表（按值）、字典（按**键**）、文本（找子串），与 `列表.包含()` 语义一致
- 同一性（M23）：`是` / `不是`——`x 是 空`、`结果 不是 假`。
  空/真/假按单例判断；数字与文本按值判断（避免 Python `is` 那种
  「有时真有时假」的随机感）；列表/字典/实例/函数按对象身份判断
- 逻辑：`与` `或` `非`（短路求值）
- 赋值：`=` `+=` `-=` `*=` `/=` `//=` `%=` `**=`
  （`//=` 与 `**=` 在 M25 之前因词法器最长匹配出错而不可用，已修复）
- 成员访问：`模块.函数`、`对象.方法(...)`、`列表[下标]`、`字典[键]`

**优先级**（松 → 紧，同一行同级）：

```
或  <  与  <  非  <  比较（== != < > <= >= 在 不在 是 不是）  <  + -  <  * / // %  <  **
```

> `非` 的优先级在 M23 修正为「比比较松、比与或紧」，与 Python 的 `not` 一致。
> 修正前 `非 年龄 >= 18` 会被解析成 `(非 年龄) >= 18`（恒为假，**静默给错答案**）；
> 现在解析为 `非 (年龄 >= 18)`，符合阅读直觉。
> 常见写法：`非 甲 与 乙` = `(非 甲) 与 乙`；`非 1 == 2` = `非 (1 == 2)`。

**链式比较**里也可以混用关键字运算符：`0 <= x 在 [1, 2]` 等价于
`0 <= x` 且 `x 在 [1, 2]`（中间值只求值一次）。

## 7.5 集合（M24）

```python
令 甲 = {1, 2, 2, 3}        # 字面量，自动去重 → {1, 2, 3}
令 乙 = 集合([3, 1, 3])      # 从列表造 → {3, 1}
令 空集 = 集合()            # 空集合（注意 {} 是空字典）
令 平方集 = {x * x 遍历 x 在 范围(4)}   # 集合推导式
```

- **有序**：元素按首次出现的顺序排列。`集合([3, 1, 3, 2])` 得到 `{3, 1, 2}`，
  打印与遍历顺序稳定可复现（这也是为什么不用「无序」的哈希集合）。
- 元素必须是**不可变的**（数字、文本…）；列表、字典放不进去，会报中文错。
- `{}` 仍是**空字典**（与 Python 一致），空集合写 `集合()`。
- 用 `长度()`、`在` / `不在`、`==`（**与顺序无关**）、`遍历` 都直接可用。
- 集合方法：

| 方法 | 说明 |
|------|------|
| `添加(值)` / `移除(值)` / `丢弃(值)` | 增删；`移除` 找不到会报错，`丢弃` 不报错 |
| `包含(值)` | 与 `值 在 集合` 等价 |
| `并集(可迭代)` / `交集(可迭代)` | 返回新集合 |
| `差集(可迭代)` / `对称差(可迭代)` | 返回新集合 |
| `转列表()` / `复制()` / `清空()` | 转换与清空 |

去重的常见写法：`令 唯一 = 集合(原列表)` 或 `令 唯一 = 集合(原列表).转列表()`。

## 7.6 切片赋值（M24）

```python
令 分数 = [90, 55, 70, 88, 60]
分数[1:3] = [95, 96]     # 替换一段
分数[:2] = [100]         # 替换开头
分数[1:] = []            # 删掉末尾
分数[::2] = [1, 2, 3]    # 带步长（要求两边个数正好相等）
```

读取切片（M18）与写入切片共用同一条求值路径，分量同样可以省略、可以用变量。
带步长赋值时两边**个数必须相等**，否则报中文错（提示长度对不上）。
文本只能读切片，不能写。

## 7.7 匿名函数与数据流水线（M24）

```python
令 加倍 = 函数(x)：x * 2          # 单表达式函数体，自动作为返回值
令 加基数 = 函数(x)：x + 基数      # 捕获外层变量（闭包）
令 加 = 函数(x)：函数(y)：x + y    # 柯里化，加(3)(4) → 7

数 = [1, 2, 3, 4, 5]
数.映射(函数(x)：x * x)                    # [1, 4, 9, 16, 25]
数.过滤(函数(x)：x % 2 == 1)               # [1, 3, 5]
数.排序按(函数(x)：-x)                     # 从大到小
数.归约(函数(累计, x)：累计 + x, 0)          # 15
```

- 匿名函数写成**一行**：`函数(参数)：表达式`。参数支持默认值与类型标注；
  需要多行逻辑就定义具名函数（`函数 名字(参数)：` 后面换行缩进）。
- 列表新增四个流水线方法：`映射` / `过滤` / `排序按` / `归约`，
  既可以传匿名函数，也可以传具名函数。
- `排序按` 的键要能互相比较（都是数字或都是文本），混着来会报中文错。

## 7.8 迭代协议（M24）

自定义对象只要定义 `迭代(自身)` 方法，就能用于 `遍历`、推导式，
以及 `总和` / `最大` / `最小` / `长度` 等会遍历的内建：

```python
类 成绩表：
    函数 初始化(自身, 记录)：
        自身.记录 = 记录
    函数 迭代(自身)：
        返回 自身.记录

令 表 = 新建 成绩表([90, 80])
遍历 分 在 表：
    打印(分)
打印(总和(表), 长度(表))     # 170 2
```

`迭代` 应返回一个可遍历的东西（列表、文本、集合、字典…）。返回自身会
无限循环，解释器会拦下并报中文错。

## 7.9 类型标注（M24）

```python
函数 折扣(价格: 小数, 比例: 小数) -> 小数：
    返回 价格 * 比例
```

- **参数标注会被校验**：调用时若实参类型不符，报中文错并指出是哪个函数、
  哪个参数、期望什么、实际是什么。三执行器行为一致。
- 认识的类型名：`整数` / `小数` / `文本` / `列表` / `字典` / `集合` /
  `布尔` / `空` / `函数` / `任意`（`值`）。`布尔` 不算 `整数`（刻意区分）。
- **不认识的标注名一律跳过**（例如 `订单: 订单`），这样标注可以同时当文档用，
  自定义类型名不会被误报。
- **返回标注目前只作文档**，不做校验（这条边界是明确的）。
- 定位是「运行时校验 + 文档」，**不是静态类型系统**：不做类型推导、
  不做编译期检查，没写标注的参数零开销。

## 7.10 变长参数（M25）

```python
函数 求和(*数)：            # 收下所有位置实参，是个列表
    令 总 = 0
    遍历 x 在 数：
        总 += x
    返回 总
打印(求和())                # 0
打印(求和(1, 2, 3))         # 6

函数 配置(**选项)：          # 收下未匹配的关键字，是个字典
    返回 选项
打印(配置(甲 = 1, 乙 = 2))   # {'甲': 1, '乙': 2}

函数 混合(甲, *余, **选)：    # 三者可以组合
    返回 [甲, 余, 选]
```

- `*参数` 收集**多余的位置实参**，`**选项` 收集**未匹配的关键字**；
  都没收到时是空列表 / 空字典（不会报错）。
- 参数顺序固定：`普通参数 → *参数 → **选项`。顺序不对会报中文错。
- `*参数` / `**选项` 不能有默认值，也不能写类型标注（元素类型不固定，
  要检查请在函数体里用 `断言`）。
- 暂不支持「`*参数` 之后再加普通参数」（那属于只能关键字传参的进阶写法）。
- 与默认值共存时，默认值只属于**普通参数**的尾部：
  `函数 f(甲, 乙 = 10, *余)` 调用 `f(1)` 得到 `甲=1、乙=10、余=[]`。
- **没有「星号展开」实参**（Python 的 `f(*列表)` / `f(**字典)`）：
  传列表就是「一个参数」。需要展开时先自己转换。

## 7.11 星号解包（M25）

```python
令 甲, *余 = [1, 2, 3, 4]      # 甲=1，余=[2, 3, 4]
令 首, *中, 尾 = [1, 2, 3, 4, 5]  # 首=1，中=[2, 3, 4]，尾=5
令 x, *y = [1]                  # x=1，y=[]（可以为空）
令 头, *尾 = "你好世界"          # 头='你'，尾=['好', '世', '界']
a, *b = [9, 8, 7]               # 不加「令」也一样
```

- 星号位置收集「其余」元素成**列表**，可以在中间或末尾；只能有一个。
- 长度要求：星号以外的固定名字都要有对应的值，否则报中文错
  （提示可以写「*余」来收剩下的）。
- 右值可以是列表、文本、集合（字典解出来的是键）。

## 7.12 上下文管理器 `用 … 为`（M26）

```python
用 打开("数据.txt") 为 文件：
    遍历 行 在 文件：
        打印(行)
# 走到这里文件已经自动关闭
```

- `用` 后面是「上下文管理器」，`为` 后面接一个名字。
- 离开代码块时自动收拾：先找对象的 `退出()`，没有就找 `关闭()` 并调用。
  正常结束、`返回`、`中断`、`抛出` 都会走到（`尝试/最终` 的语义）。
- 自定义类定义 `进入()` 可以决定绑定什么值；不写就绑定对象本身。
- 退出**不会**吞掉异常（有意不做）：出错了就让它照常报出来，
  否则「出问题快速找到」会变难。

它等价于下面这段（解析期就是这样脱糖的，所以三个执行器行为必然一致）：

```python
__用_1__ = 打开("数据.txt")        # 临时变量存原对象
文件 = 进入上下文(__用_1__)
尝试：
    ……你的代码……
最终：
    退出上下文(__用_1__)
```

> 退出作用在**原来的对象**上，而不是绑定后的名字——`进入` 完全可以返回
> 别的东西（Python 的 `__enter__` 也允许），拿返回值去退出会找错对象。

### 文件对象（`打开`）

```python
用 打开("a.txt", "写") 为 f：
    f.写行("第一行")
用 打开("a.txt", "追加") 为 f：
    f.写("追加的内容")
用 打开("a.txt") 为 f：
    遍历 行 在 f：            # 文件本身可遍历（按行）
        打印(行)
```

模式：`读` / `写` / `追加` / `读写`（也认 `r` `w` `a` `r+` `w+` `a+`）。
一律按 UTF-8 读写——Windows 上的默认编码是 GBK，中文会写乱。

| 方法 | 作用 |
|------|------|
| `读(数量?)` | 读整篇；给了数量就读前 N 个字符 |
| `读行()` | 读一行（不含换行符）；已经到末尾给「空」 |
| `读所有行()` | 一次读成列表 |
| `写(内容)` | 写文本（不加换行）|
| `写行(内容)` | 写一行（自动加换行）|
| `关闭()` | 关闭（重复调用不报错）|
| `刷新()` / `位置()` / `定位(偏移)` | 落盘 / 当前位置 / 跳到位置 |

打印文件对象显示 `<文件 路径（状态）>`，便于排错。

> 跨语言宿主（Node / Rust）都已同步 `打开` 与 `进入上下文` / `退出上下文`
> （Node 在 M27、Rust 在 M29，两边都有对拍测试），所以 `用 … 为` 与文件
> 操作在那边照常可用。

## 7.13 自定义对象打印：`文本()`（M26）

```python
类 分数：
    函数 初始化(自身, 分子, 分母)：
        自身.分子 = 分子
        自身.分母 = 分母
    函数 文本(自身)：
        返回 文本(自身.分子) + "/" + 文本(自身.分母)

打印(新建 分数(1, 3))        # 1/3
```

- 类里定义 `文本(自身)` 后，`打印(对象)` 与 `文本(对象)` 都用它的返回值；
  放进列表、字典里打印也一样生效。
- 没定义时保持 `<类名 实例>`，子类继承父类的 `文本`。
- `文本` 必须返回文本，否则报中文错（说清「要返回文本」）。

## 7.14 精确小数（M26）

```python
打印(0.1 + 0.2 == 0.3)                          # 假（二进制浮点）
打印(精确("0.1") + 精确("0.2") == 精确("0.3"))    # 真

令 价 = 精确("19.99")
打印(价 * 3)         # 59.97
打印(价.舍入(2))      # 19.99（四舍五入）
```

- `精确(值)` 把数字或数字文本转成**十进制**小数。从普通小数转时走 `str`，
  所以 `精确(0.1)` 就是 0.1，不会把二进制尾巴带进来。
- 四则运算、比较、`总和`/`最大`/`最小`/`排序` 都支持；与普通整数/小数
  混算时按十进制处理（所以 `精确("0.3") == 0.3` 为真）。
- 方法：`舍入(位数 = 2)`（四舍五入；负位数表示舍到十位、百位）、
  `绝对值()`、`转文本()`。
- **普通小数 `0.1` 仍是二进制浮点**，与 Python 一致——不偷偷改语义，
  需要精确的地方显式写 `精确(...)`。
- 跨语言宿主都已同步这个内建：Node 侧用 BigInt 自己实现十进制（M27），
  Rust 侧零依赖手写 BigInt（M29），两边的 `精确("1")/精确("3")` 都与
  Python 逐字节一致（有对拍）。

## 7.15 值的显示规则（M27 统一）

**一个值只有一种写法**。`打印(值)`、`文本(值)`、字符串插值 `` `{值}` ``、
`打印([值])`、REPL 回显，全部走同一套规则（`runtime.jishi_repr`）：

| 值 | 顶层显示 | 容器内显示 |
|----|---------|-----------|
| `空` | `空` | `空` |
| `真` / `假` | `真` / `假` | `真` / `假` |
| 文本 | 原样：`甲` | 带引号：`'甲'` |
| 列表 | `[1, 真, 空, '甲']` | 同左 |
| 字典 | `{'键': 1}` | 同左 |
| 自定义对象 | `文本()` 的返回值，否则 `<甲 实例>` | 同左 |
| 精确小数 | `1.50` | 同左 |
| 文件 | `<文件 路径（状态）>` | 同左 |

```python
打印(空, 真, 假)              # 空 真 假
打印([1, 真, 空, "甲"])        # [1, 真, 空, '甲']
打印(`结果是 {真}`)            # 结果是 真
```

- **空 / 真 / 假 一律中文化**，与源码里的写法一致；从 Python 抄来
  `True`/`False`/`None` 会直接报错并提示中文写法（见 §11 容错解析）。
- 文本在**顶层不加引号**（用户要的就是那串字），在**容器里加引号**
  （否则分不清 `['甲']` 里的是文本还是变量）——与 Python 的 `print`/`repr`
  分工一致。REPL 回显算「容器内」这一侧：`>>> "甲"` 回显 `'甲'`。
- 字典用半角 `: `，与源码字面量 `{"甲": 1}` 写法一致——打印结果能直接抄回代码。
- 标准库/桥接返回的原生 Python 值（`bool`、`None`、`list`…）也走这套规则，
  所以 `路径.存在(...)` 显示「真/假」而不是 `True`/`False`。

## 8. 语句

### 变量
```python
令 分数 = 60

数据[0] = 100      # 下标赋值
```

### 切片（M18.1）
```python
令 a = [1, 2, 3, 4, 5]
a[1:3]        # [2, 3]     起:止
a[::-1]       # [5, 4, 3, 2, 1]   倒序
```

- 解包右值限列表（含 Python 桥接的元组），数目不符会中文报错

### 导入

Python 桥接规则（M3）：
- 导入的 Python 模块成员原样可用（函数、类、常量）；下划线开头的内部成员不可见

- 基石函数可以直接传给 Python 高阶函数（如 `builtins.map(基石函数, 列表)`）
- Python 侧抛出的异常自动翻译成中文错误（找不到文件、权限不足、递归过深…）

本地包规则（M10.2）：
- 包是 `.jishi/packages/名字/` 目录，含 `包.json`（名字/版本/依赖）与若干 `.jsh` 模块
- 执行所有模块后，顶层定义的函数/变量作为包成员导出
- 搜索顺序：项目目录 `.jishi/packages/` → 用户目录 `~/.jishi/packages/`

包清单 `包.json` 字段：

```json
{
  "名字": "某包",
  "版本": "1.0.0",

  "描述": "可选说明"

```

- `依赖`：名字 → 版本约束。导入某包时会**先递归加载其依赖**，校验依赖版本
  满足约束后，把依赖包对象注入到该包模块的命名空间（模块里可直接 `依赖名.成员`，
  无需重复导入）。
- 版本约束语法：`*` 任意；`1.2.3` 精确；`>=1.0.0` / `<=2.0.0` / `>` / `<`；
  `^1.2.3` 主版本锁定（>=1.2.3 且 <2.0.0）。约束不满足报中文错误。
- 循环依赖（甲依赖乙、乙依赖甲）会报「检测到循环依赖：甲 → 乙 → 甲」。

远端索引格式（M10.2，先静态 JSON 文件托管，不建站）：

```json
  "版本": 1,
  "包": {
    "某包": {
      "版本": "1.0.0",

      "依赖": {"基础库": ">=1.0.0"},
      "描述": "……"
    }
  }
}
```

- `格式` 固定为 `jishi-package-index`，`版本` 为索引格式版本号（当前 1）。
- 校验逻辑在 `jishi/packages.py`（`parse_index` / `resolve_package` /
  `version_satisfies`），供 `jishi 安装` 命令（M14）复用。

- 安装目标：项目 `.jishi/packages/`（不存在时自动创建）；搜索顺序与导入一致
  （先项目后用户目录）。
- 从索引安装会「读索引 → 取下载地址 → 下载 zip → 解压安装」全自动完成。

```python
    返回 姓名 + "今年" + 文本(年龄) + "岁"
```

### 8.9 异常处理

```python
尝试:
    令 结果 = 整数("不是数字")
捕获 类型错误 为 e:
    打印("输入不对：", e.消息)
捕获 异常 为 e:            # 「异常」是所有错误的基类，抓得住一切
    打印("其他错误：", e.类型)
最终:
    打印("无论如何都会执行")
```

- `捕获` 可以有多个，从上往下匹配第一个符合的；`最终` 最多一个且可选。
- 捕获条件按**错误类型名**匹配，基类能抓子类：`异常` > `运行期错误` >
  `类型错误`/`值错误`/`索引错误`/`键错误`/`除零错误`/`文件错误`/`断言错误`。
- `断言(条件, 消息)` 失败抛出的就是「断言错误」（M23），因此它既能用
  `捕获 断言错误` 精确接住，也能用 `捕获 运行期错误` 兜住。
- 不写类型就是全抓：`捕获 为 e:`（或干脆 `捕获:`）。
- `抛出 表达式` 抛出任意值；非异常对象会被自动包成「异常」，原值留在 `e.消息`：

```python
函数 取折扣价(原价, 折扣):
    如果 折扣 <= 0 或 折扣 > 1:
        抛出 值错误("折扣必须在 0 到 1 之间")
    返回 原价 * 折扣
```

- 异常对象可读属性：`e.消息`（中文说明）、`e.类型`（如「值错误」）。
- 未被捕获的异常照常渲染成中文报错（含文件行列），程序终止。

### 8.10 类与继承

```python
类 动物:
    函数 初始化(自身, 名字):
        自身.名字 = 名字
    函数 叫(自身):
        打印(自身.名字, "在叫")

类 猫 继承 动物:
    函数 叫(自身):            # 覆盖基类方法
        打印(自身.名字, "喵喵")

令 咪咪 = 新建 猫("咪咪")
咪咪.叫()
```

- `类 名字:` 定义类；类体里写方法和**类变量**（M23）。
- **类体里只能写三样**（M35）：**方法**（`函数 …`）、**类变量**（`名字 = 值`）、
  **空类占位**（单独一行 `:`——基石没有 `pass` 关键字）。写别的（表达式语句、
  `+=` 这类增强赋值、下标/属性赋值）在**解析期**就报错并给出正确写法。
  以前这条不统一：树遍历会报错，而两个字节码执行器会**静默忽略**
  （`x += 5` 甚至被当成 `x = 5` 静默算错），所以统一挪到解析期拦下。
- 方法第一个参数约定叫 `自身`（普通标识符，不是关键字），表示实例本身，
  调用 `实例.方法(...)` 时自动绑定。
- `初始化` 是约定俗成的构造方法，`新建 类(参数)` 时自动调用；
  没定义 `初始化` 则 `新建 类()` 造空实例，传参报错。
- `继承 基类` 让子类复用基类方法，子类同名方法覆盖；基类必须确实是类。
- 实例字段用 `自身.名字 = 值` 创建，`实例.字段` 读取；不同实例互不影响。
- 类型名：类显示为「类 名字」，实例显示为「名字 实例」。

**类变量（M23）**——写在类体里、所有实例共享的名字：

```python
类 计数器：
    总数 = 0                  # 类变量
    名字 = "计数器"
    函数 加(自身, n)：
        计数器.总数 += n        # 用类名读写，或 自身.总数 读也行
```

- 值在**定义类的外层作用域**求值，所以 `值 = 外层常量 * 2` 能用外层名字；
- 查找顺序与 Python 一致：**实例字段 → 类变量（含基类）→ 方法**，
  同名时实例字段遮蔽类变量；
- `类名.变量 = 值` 写在类自己的类变量表里，不影响已造出的实例字段；
- 继承时类变量浅拷贝合并，子类可覆盖；可变对象（列表等）两边共享同一份。

**`超()` 调父类方法（M23）**：

```python
类 动物：
    函数 初始化(自身, 名字)：
        自身.名字 = 名字
    函数 叫(自身)：
        返回 自身.名字 + "叫了一声"

类 狗 继承 动物：
    函数 初始化(自身, 名字, 品种)：
        超().初始化(名字)          # 调基类的构造方法
        自身.品种 = 品种
    函数 叫(自身)：
        返回 超().叫() + "，汪汪"   # 调基类同名方法再追加
```

- `超()` 指向「**定义这个方法的类**的基类」，因此在多级继承里不会绕回自己
  （`小狗 → 狗 → 动物` 三级链能正确逐层向上，与 Python 的零参数 `super()` 一致）；
- 只能在方法里用（方法必须有第一个参数 `自身`）；写在类外或没有 `自身`
  参数的方法里，解析期即报错并给出写法提示；
- 找不到基类或基类没有该方法时，报错会列出基类可用的方法。

### 8.11 模式匹配 `匹配` / `情形`（M34）

```python
匹配 分数：
    情形 90：                    # 单值
        打印("优秀")
    情形 80, 85：                # 多值：命中任一个即可
        打印("良好")
    情形 如果 分数 >= 60：        # 只有条件（守卫链，最常见的写法）
        打印("及格")
    情形 其他：                  # 兜底，要放最后
        打印("继续努力")
```

四种分支写法：

| 写法 | 含义 |
|------|------|
| `情形 值：` | 待匹配值与「值」相等即命中 |
| `情形 值1, 值2：` | 命中任一个即可 |
| `情形 值 如果 条件：` | 先比较值，**再看条件** |
| `情形 如果 条件：` | 只有条件（相当于一个 `如果` 分支） |
| `情形 其他：` | 兜底（不带条件的通配，必须放最后） |

- **待匹配值只求值一次**：`匹配 取下一个()：` 不会因为分支多而跑多次；
- 模式可以是任意表达式（变量、运算、容器字面量）：`情形 基准 + 5：`；
- 分支体里 `中断`/`继续`/`返回` 行为与普通块一致；
- 通配用的是 `其他` 这个词（`_` 也行）；想匹配一个**名叫「其他」的变量**，
  写 `情形 (其他)：`（加括号走普通表达式）；
- 实现是**解析期脱糖**成 `如果/否则如果/否则` 链，所以三个执行器
  （树遍历 / Python VM / C VM）与两个跨语言宿主（Node / Rust）行为必然一致。

### 8.12 枚举 `枚举`（M34）

```python
枚举 颜色：
    红 = 1
    绿 = 2
    蓝 = 3

枚举 方向：      # 不写值：自动接着编号（从 1 起）
    上
    下
    左
    右
```

- 成员是**实例**（不是裸值），所以 `打印(颜色.红)` 给 `颜色.红`
  （容器里也一样），`.名字` / `.值` 分别取名字与值；
- `==` 按**身份**比：`颜色.红 == 颜色.红` 为真、`颜色.红 == 1` 为假
  （与 Python 的 `Enum` 一致）；
- `类型(颜色.红)` 给 `颜色 实例`、`类型(颜色)` 给 `类 颜色`；
- **遍历所有成员**用 `颜色.全部`（一份清单）：
  `遍历 c 在 颜色.全部：`；
- 成员值可以是文本等任意值（`待办 = "todo"`），此时后面的成员不能再省值
  （没法自动编号，报错会说清）；
- 枚举体里**只写成员**，不写方法（要方法就用 `类`）；
- 实现同样是**解析期脱糖**：`类 颜色：` + 若干 `颜色.红 = 新建 颜色(…, …)`。

## 9.5 对象方法（M1）

方法通过 `对象.方法(...)` 调用；列表与字典的方法为原地修改，文本方法返回新值。

| 对象 | 方法 |
|------|------|

## 11. 中文报错

所有错误以中文呈现，带错误码、行列定位与修正建议：

```
错误 E0106：关键字与后面的内容粘连了（「如果分数」被当成了一个名字，但它的开头是关键字「如果」）
  ┌─ 文件.jsh:1:1
  │
1 │ 如果分数 > 60：
  │ ~^
  │
  提示：你是不是想写「如果 分数」？关键字和后面的内容之间要留空格
```

错误码分段：`E01xx` 词法、`E02xx` 语法、`E03xx` 语义、`E2xxx` 运行期。

### 11.0 调用栈回溯（M17）

运行期错误若发生在函数调用深处，报错下方会附带「调用链（从外到内）」，标明
每一层是「哪个函数」在「第几行」被调用：

```
错误 E2003：索引越界（list index out of range）
  ┌─ 脚本.jsh:3:9
  3 │     打印(x[10])
    │         ^
  │
调用链（从外到内）：
  外层 ← 第 8 行
  中层 ← 第 7 行
  里层 ← 第 5 行
```

- 递归超限（`RecursionError`）同样走中文翻译 + 调用链 + 「是不是忘了结束条件」建议；
- 协议/沙箱的 JSON 错误里也带 `trace` 字段（agent 可程序化读取）；
- 调用链最多显示最近 20 帧，避免深层递归刷屏。

### 11.1 容错解析（M7.5）

基石会识别「用英文写了 Python 关键字/内建」的常见错误（大模型写中文代码时
容易 fallback 回英文），并直接给出中文对应建议：

```python
def f(x):        # → 「def」是英文关键字，你是不是想写「函数」？
print(1)         # → 「print」是 Python 内建，基石里叫「打印」
令 x = True      # → 「True」是英文写法，你是不是想写「真」？
令 y = 1 and 2   # → 「and」是英文写法，你是不是想写「与」？
```

覆盖三类：英文语句关键字（def/if/for/while/return/import/class/try…）、
值/运算符关键字（True/False/None/and/or/not/in/is）、内建函数
（print/len/range/int/float/str/type/min/max/sum/reversed）。
英文普通变量名（`a`、`data` 等）不受影响。

## 12. 已知边界（v1.0 冻结时的诚实声明）

以下特性**当前不支持**，已诚实标注，留待后续版本评估：

1. **Rust 宿主的剩余边界**（M33 后：标准库已补齐到 14 个模块）：
   整数到 `i128` 就到边界（越界明确报错）、绑定方法的 `是`/`不是` 明确报错、
   精确小数的 `**` 只支持整数指数、`压缩.打包` 写 `stored`（不压缩，
   文件大一点但完全合规）、非 Windows 平台上 `https://` 明确报错。
   已支持的（方法调用/高阶方法/集合/文件与上下文/精确小数/类型标注/同一性/
   切片/输入/排序/**14 个标准库模块**）全部有对拍测试；
   详见 `docs/embed.md` 的支持程度表与 `rust/README.md`。
2. **JS 宿主的剩余边界**：`node/` 已补齐到 **M34**（含 M32 的大整数
   `BigInt`、类与函数显示、精确小数精度，以及 M34 的**类变量**与
   模式匹配/枚举），剩下的是 `导入 … 从 python` 不支持（无 Python 运行时）、
   `网络` 是子进程同步封装（每次请求多约 40ms）。

以上边界均属「已知、诚实标注、留待演进」，不影响 v1.0 的核心语言特性冻结。
