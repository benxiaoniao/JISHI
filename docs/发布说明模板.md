## 快速开始

### 方式一：下载发行包（推荐，无需 Python）

1. 到 <https://基石.cn/download.html> 取对应平台的产物
   （Windows 安装程序 `setup.exe` / 免安装 `zip`、Linux `tar.gz`、macOS `tar.gz`）
2. **Windows**：双击 `setup.exe`（用户级安装，不改系统、不弹 UAC）；
   免安装版解压即可用
3. **Linux / macOS**：解压后 `bash install.sh`
4. **新开终端**，`jishi --version` 看到版本号即成功
5. 写第一个程序：

```
令 名字 = "世界"
打印("你好，" + 名字)
```

保存为 `hello.jsh`，运行 `jishi hello.jsh`。

### 方式二：从源码构建（开发者途径）

```bash
git clone https://github.com/benxiaoniao/JISHI.git
cd JISHI/rust && cargo build --release    # 产出 rust/target/release/jishi-rs
```

> ⚠️ **没有 `pip install` 这条路**：基石**不发布到 PyPI**（2026-09-22 决定），
> `[project.scripts]` 已清空。安装只走发行包或上面的 cargo 构建。
> Python 实现（`oracle/jishi/`）已退役，只作判据基准。

### 方式三：源码运行（判据基准 / 参考实现）

```bash
git clone <仓库>
cd 基石
python -m oracle.jishi.cli hello.jsh     # 仅用于对照与开发，不是安装方式
```

## 校验下载完整性

每个发行包附带 `SHA256SUMS`，下载后校验：

```bash
# Linux/macOS
sha256sum -c SHA256SUMS
# Windows PowerShell
Get-FileHash jishi-{版本号}-windows-x64.zip -Algorithm SHA256
```

⚠️ 若清单里出现 `SHA256SUMS` **自己那一行**（哈希以 `e3b0c442…` 开头 = **空串**的
SHA256），那行是历史上一个 bug 留下的，**忽略它**（0.2.3 起不再产生）。
