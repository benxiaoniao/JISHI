## 快速开始

### 方式一：下载发行包（推荐，无需 Python）

1. 下载对应平台的发行包（zip / tar.gz）
2. 解压后运行安装脚本：
   - Windows：右键 `install.ps1` →「使用 PowerShell 运行」，或
     `powershell -ExecutionPolicy Bypass -File install.ps1`
   - Linux/macOS：`bash install.sh`
3. **新开终端**，运行 `jishi --version` 看到版本号即成功
4. 写第一个程序：

```
令 名字 = "世界"
打印("你好，" + 名字)
```

保存为 `hello.jsh`，运行 `jishi hello.jsh`。

### 方式二：从源码安装（开发者途径）

```bash
pip install git+https://github.com/benxiaoniao/JISHI.git
jishi --版本
```

> **不要写 `pip install jishi`**：基石不发布到 PyPI（2026-09-22 决定），
> 自建分发通道在规划中（`docs/路线图.md`「方向四」）。

### 方式三：源码运行

```bash
git clone <仓库>
cd 基石
python -m jishi.cli hello.jsh
```

## 校验下载完整性

每个发行包附带 `SHA256SUMS` 文件，下载后校验：

```bash
# Linux/macOS
sha256sum -c SHA256SUMS
# Windows PowerShell
Get-FileHash jishi-0.1.0-windows-x64.zip -Algorithm SHA256
```
