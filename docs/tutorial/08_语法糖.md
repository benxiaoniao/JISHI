# 第 8 章：语法糖进阶（M7）

第 2–6 章用的都是「基础写法」。基石在 M7 补了一批**语法糖**，
让代码更短、更接近日常表达。这一章把这些技巧一次讲全。

## 8.1 多赋值与解包

一行同时给多个变量赋值：

```jsh
令 a, b = 1, 2        # a=1，b=2
令 x, y = [3, 4]      # 从列表解包
a, b = b, a           # 交换两个变量的值（不用中间变量）
```

函数也能「一次返回多个值」：

```jsh
函数 除法(a, b):
    返回 a // b, a % b    # 同时返回商和余数

令 商, 余 = 除法(17, 5)    # 商=3，余=2
```

遍历时也能解包：

```jsh
令 对们 = [["小明", 8], ["小红", 9]]
遍历 名字, 年龄 在 对们:
    打印(名字, 年龄)
```

## 8.2 默认参数

函数参数可以带默认值，调用时省略就用默认：

```jsh
函数 打招呼(名字, 语气 = "你好"):
    打印(语气, 名字)

打招呼("小明")            # 你好 小明
打招呼("小红", "嗨")      # 嗨 小红
```

## 8.3 列表 / 字典推导式

一行生成列表或字典，替代「先建空列表再循环追加」：

```jsh
# 普通写法
令 平方 = []
遍历 x 在 范围(1, 6):
    平方.追加(x * x)

# 推导式（等价，一行）
令 平方 = [x * x 遍历 x 在 范围(1, 6)]

# 带条件
令 偶数 = [x 遍历 x 在 范围(1, 21) 如果 x % 2 == 0]

# 字典推导式
令 平方表 = {x: x * x 遍历 x 在 [1, 2, 3]}
```

## 8.4 文本插值

用反引号 `` ` `` 包裹文本，`{表达式}` 会被求值插入——比「拼接 +」清爽得多：

```jsh
令 名 = "基石"
令 版本 = "1.0"
打印(`欢迎使用 {名} {版本} 版`)

令 分数 = [92, 88, 95]
打印(`平均分：{总和(分数) / 长度(分数)}`)
```

> 注意：插值里的表达式会先求值再转文本，所以可以写任意表达式，不只是变量。

## 8.5 小结

- 多赋值/解包：一行管多变量，交换、多返回、遍历解包都靠它
- 默认参数：省略不写就用默认
- 推导式：`[表达式 遍历 x 在 序列 如果 条件]` 一行生成列表/字典
- 文本插值：反引号 + `{表达式}`，告别一堆 `+` 拼接
