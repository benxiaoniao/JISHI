# 第 14 章：网页——用构件拼出一个真页面

第 13 章起了一个接口，用浏览器打开只能看到一段 JSON。这一章让同一个浏览器
**看到页面**：有表单、有表格、有按钮。

> 配套示例：`examples/tutorial/14_网页.jsh`
> 跑一次会在同目录生成 `记账.html`，双击就能看见。

## 14.1 走哪条路：服务端渲染

做网页有三条常见路：前端框架（React/Vue）、模板语言（Jinja/PHP）、**函数拼字符串**。
基石走第三条，理由很直接：

> 页面**就是一段文本**。既然语言里已经有字符串、函数、循环，那拼页面就不该
> 再学一套构建工具。要写一个表单，先装 npm、配打包、学 JSX —— 那不是中文编程，
> 那是又学了一门语言。

代价也要说清楚：**这条路上没有响应式**。点按钮不会局部刷新，要么提交表单
整页重来，要么自己写一小段 JS（第 16 章那种）。

## 14.2 五件套：表单控件

```jsh
导入 html

html.输入框("金额", "金额", "number")        # 名字、说明、类型
html.多行文本("备注", "备注", "", 3)          # 名字、说明、初值、行数
html.下拉("类别", ["餐饮","交通"], "类别", "餐饮")   # 选项、默认选中
html.多选("标签", ["工作","生活"], "分类")
html.按钮("记一笔")
```

参数顺序只有一条要记：**名字在前，说明在后**。名字是提交时用的键
（`请求["表单"]["金额"]`），说明是给人看的标签。

## 14.3 🔴 转义：这一章唯一必须记住的规矩

用户输入**一律转义**。不转义会怎样：有人在备注里写
`<script>偷走你的登录凭证</script>`，你的页面就替他执行了 —— 这叫 XSS。

好消息是**构件默认就转义**，你什么都不用做：

```jsh
html.标签("p", "1 < 2 与 <b>粗体</b>")
# → <p>1 &lt; 2 与 &lt;b&gt;粗体&lt;/b&gt;</p>
```

坏消息是有时候你**确实**要插一段自己拼好的 HTML（比如上面那个表格）。
那时候用 `html.原样(片段)`：

```jsh
html.标签("div", html.原样("<hr>"))
```

`原样` 这个名字是**故意起得这么扎眼**的 —— 它让你在代码里一眼看见
「这里跳过了转义」，review 的时候好抓。**用户填的东西永远不许放进 `原样`。**

## 14.4 表格：别手拼 `<tr><td>`

先把数据做成「表格值」，再画出来：

```jsh
令 账 = 表格.从记录([
    {"日期": "11-01", "项目": "早餐", "金额": "12"},
    {"日期": "11-01", "项目": "地铁", "金额": "3"},
])
打印(html.由表格(账, 真))     # 第二个参数：画不画斑马纹
```

`表格` 模块本来是给 Excel 用的（第 12 章），这里复用它 —— **同一份数据
既能导出 `.xlsx`，也能直接画成网页表格**，不用转两次。

## 14.5 整页：`页面` 给骨架，你只填内容

```jsh
令 页 = html.页面("记账", [标题, 表单, 表格片段], [["首页", "index.html"]])
```

第三个参数是导航，**每一项是 `[文字, 地址]`**（文字在前）。

> ⚠️ 这里有个**已知的不一致**，写的时候别记混：
> `html.页面` 的导航是 **`[文字, 地址]`**，而下一章 `站点.布局` 的 `导航项`
> 是 **`[地址, 文字]`**。两个模块各按各的来，反了不会报错，只会**链接文字变成
> 一串路径**。已记进 CHANGELOG 待统一（统一要动已有调用方，留到 0.4）。

它替你把 `<html>/<head>/<meta charset>/<title>/<nav>/<footer>` 都放好，
其中三件**不做会出事**：

| 它做了什么 | 不做会怎样 |
|---|---|
| `<meta charset="utf-8">` | 中文全是乱码 |
| `<meta name="viewport">` | 手机上整页缩小成一条 |
| 导航 + 页脚 | 每页都要自己抄一遍，抄漏一页就断链 |

样式是**内置常量**，不引 CDN —— 断网也好看，这对「传上去就能用」很重要。

## 14.6 写出去

```jsh
文件.写文本("记账.html", 页)
```

到这里你已经有一个**能双击打开的页面**了。要让它从「一个文件」变成
「一个站」，下一章。

## 14.7 三个坑

1. **`html` 是模块名，别拿它当变量名**。`令 html = ...` 会把模块遮住，
   后面所有 `html.标签(...)` 全报「没有这个函数」。
2. **导航项是 `[文字, 地址]`**（文字在前）。反了不报错，只是链接文字变成 URL ——
   而且**下一章的 `站点` 是反的**（`[地址, 文字]`），跨章的时候要格外小心。
3. **拼出来的 HTML 没有缩进**。想看排版就打开浏览器开发者工具，
   别指望字符串好看 —— 它是给浏览器看的，不是给人读的。
