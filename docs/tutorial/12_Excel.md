# 第 12 章：Excel——把表格交给别人，也读别人交来的表

学校和公司里的数据，最后十有八九要落成 **`.xlsx`**：成绩单要发给家长、报表要交给领导、
统计数据要从同事那张表里捞。这一章讲 `Excel` 模块怎么把 `表格` 写出去、再读回来。

> 配套示例：`examples/tutorial/12_成绩单Excel.jsh`（能直接跑，跑完自己清理）

## 12.1 四个函数，覆盖全部操作

| 函数 | 干什么 |
|---|---|
| `Excel.写工作簿(路径, 表, 表名="Sheet1")` | 一张 `表格` → 一个单表 `.xlsx` |
| `Excel.写多表(路径, 表们)` | `{"表名": 表格, …}` → 一个多标签页的 `.xlsx` |
| `Excel.读工作簿(路径)` | → `{"路径": …, "工作表们": [...]}` |
| `Excel.读工作表(簿, 名)` | → **`表格` 对象**（第一行当表头） |

📌 **读出来是 `表格`**，和第 6、7 章用的类型是**同一个** ——
`表格.表头 / 数据行 / 挑选 / 筛选 / 排序按 / 汇总 / 分组汇总 / 转文本` 全都能直接接上。
学会一个就够用了。

## 12.2 导出：先把数据变成 `表格`

`写工作簿` 收的是**表格**（不是行列表）。手里是「记录列表」的话，用 `表格.从记录` 转一下：

```jsh
导入 Excel
导入 表格

令 成绩们 = [
    {"姓名": "小明", "语文": 92, "数学": 88},
    {"姓名": "小红", "语文": 85, "数学": 97},
]
Excel.写工作簿("成绩单.xlsx", 表格.从记录(成绩们), "成绩")
```

- 字典的**键顺序**就是列顺序（第一个记录先出现的键排前面）；
- 第三个数是**标签页名字**，不写就是 `Sheet1`；
- 想一个文件里放多张表（成绩 / 统计 / 明细），用 `写多表`：

```jsh
Excel.写多表("成绩单.xlsx", {
    "成绩": 表格.从记录(成绩们),
    "统计": 表格.从记录(统计们),
})
```

📌 字典的**书写顺序**就是标签页顺序。

## 12.3 读回来：两步

```jsh
令 簿 = Excel.读工作簿("成绩单.xlsx")
打印(簿["工作表们"])          # ['成绩', '统计']

令 成绩 = Excel.读工作表(簿, "成绩")
打印(表格.表头(成绩))          # ['姓名', '语文', '数学']
遍历 行 在 表格.数据行(成绩)：
    打印(行)                  # ['小明', 92, 88]
```

为什么分两步？`读工作簿` 的返回值里**带着路径** —— 第二步还要靠它去打开文件。
只给你一个名字列表，第二步就不知道读哪个文件了。

## 12.4 拿到表格以后：汇总、排行、打报表

```jsh
# 一科的平均/最高/最低，一次拿回五个数
令 统 = 表格.汇总(成绩, "数学")
打印(统["平均"], 统["最高"])        # 键是 个数/总和/平均/最大/最小

# 排行：按总分从大到小
令 排行 = 表格.排序按(带总分的表, "总分", 真)

# 打一张对齐的报表（中文按 2 列算宽度，数字右对齐）
打印(文本.对齐表([["姓名", "总分"], ["小红", 273], ["小明", 259]]))
```

⚠️ `对齐表(行们, 小数位)` 的「小数位」对**所有数字列**生效。
一列是整数总分、一列是一位小数的平均，就会一起变成 `273.0` ——
要么统一位数，要么把那一列先转成文本（会变成左对齐）。

## 12.5 读「别人的表」的五个坑

别人的表不会按你的规矩来。下面五条是从真实文件里踩出来的。

### ① `.xls` 读不了

只认 `.xlsx`。老的 `.xls` 是二进制格式，会明确告诉你：

```
错误 E2005：「假.xls」不是一个 .xlsx。Excel 的 .xlsx 其实是 zip 包，
老的 .xls 是二进制格式、读不了 —— 用 Excel 打开它「另存为」.xlsx 再试
```

### ② 第一行一定是表头

`读工作表` 把**第一行当表头**（与 `表格.读表格` 同一口径）。
可很多表第一行是**标题**（「2026 秋 期末成绩单」），第二行才是真表头 ——
这时得自己重建一张：

```jsh
令 原始 = 表格.数据行(读回来的)      # 第一行是标题
令 真表头 = 原始[1]                  # 第二行才是真表头
令 干净 = []
遍历 行 在 原始[2:]：
    令 一条 = {}
    遍历 对 在 配对(真表头, 行)：
        一条[对[0]] = 对[1]
    干净.追加(一条)
令 表 = 表格.从记录(干净)
```

📌 **表头空、重名都照原样留着**，模块不替你改名 —— 改名会让你对不上 Excel 里看到的东西。

### ③ 空单元格是 `空`，而且**汇总会报错**

「缺考」那一格读出来是 `空`。`表格.汇总` 遇到它会报：

```
列「英语」里有不是数字的值「空」，没法汇总
```

**这是故意的**：把缺考当 0 分静默算进平均，才是真正的灾难（差好几分还没人发现）。
要让缺考按 0 分算，就自己补：

```jsh
函数 补零(t)：        # 逐格看，空就换 0，再造一张表回来
    令 头 = 表格.表头(t)
    令 新行们 = []
    遍历 行 在 表格.数据行(t)：
        令 一条 = {}
        遍历 对 在 配对(头, 行)：
            令 值 = 对[1]
            如果 值 == 空：
                值 = 0
            一条[对[0]] = 值
        新行们.追加(一条)
    返回 表格.从记录(新行们)
```

### ④ 日期读出来是**数字**

Excel 里日期不是日期，是「从 1900-01-01 起第几天」加一个显示格式。模块**不做换算**，
读出来就是 `45000` 这种数。要日期就自己换 —— 起点是 **1899-12-30**：

```jsh
导入 日期
打印(日期.加天数(45000, "1899-12-30"))     # 2023-03-15
```

⚠️ **1900 年 3 月之前**会差一天（Excel 有个著名的「1900 年是闰年」bug，
它认为 1900-02-29 存在）。做历史数据的话留意这一条。

### ⑤ 只读「值」，不读公式、样式、合并单元格

- **公式**：只取单元格里**缓存的计算结果**；没算过（从没在 Excel 里打开过）就是 `空`。
  基石不去求值别人的公式；
- **合并单元格**：只有左上角那格有值，其余是 `空`（不做「合并」这个概念）；
- **样式/批注/条件格式**：不读。

## 12.6 完整示例

`examples/tutorial/12_成绩单Excel.jsh`：导出成绩单 → 读回来 → 三科平均 → 总分排行
（对齐报表）→ 缺考演示（报错 + 补零）→ 日期序号换算 → 清理。

```bash
jishi examples/tutorial/12_成绩单Excel.jsh
```

输出（节选）：

```
已写出 成绩单.xlsx
工作簿里有： ['成绩']
语文 平均 85.0 分（最高 92，最低 78）
---- 总分排行 ----
姓名  总分
小红  273
小明  259
小刚  228
直接汇总 → 列「英语」里有不是数字的值「空」，没法汇总
缺考按 0 分算 → 39.5 分
Excel 里的 45000 指的是： 2023-03-15
```

跑完 `成绩单.xlsx` 会被删掉。想留着看，把最后两行注释掉 —— 用 Excel / WPS /
LibreOffice 打开它，和手写的一模一样。

## 12.7 练习

1. **多表导出**：把「成绩」和「统计」写成同一个文件的两个标签页，用 `读工作簿` 确认
   `工作表们` 是两个名字。
2. **分类汇总**：加一列「班级」，用 `表格.分组汇总(表, "班级", "数学")` 算各班平均。
3. **报表补齐**：把总分排行做成「姓名 / 总分 / 名次」三列（名次就是遍历时的序号 + 1）。
4. **坏输入**：故意 `读工作簿("不存在.xlsx")`，看报错说了什么。

## 12.8 小结

| 想做的事 | 写什么 |
|---|---|
| 一张表写出去 | `Excel.写工作簿(路径, 表, 表名)` |
| 多张表写一个文件 | `Excel.写多表(路径, {"表名": 表格})` |
| 看有哪些表 | `Excel.读工作簿(路径)["工作表们"]` |
| 读某张表 | `Excel.读工作表(簿, 名)` → `表格` |
| 统计 / 排行 / 报表 | `表格.汇总` · `表格.排序按` · `文本.对齐表` |
