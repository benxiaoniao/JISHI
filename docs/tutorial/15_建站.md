# 第 15 章：建站——把几个页面变成一个能传服务器的站

上一章拼出了一个 `.html` 文件。可真要放到网上，「一个文件」是不够的：
要有样式表、要有 `sitemap.xml`、要让浏览器**不会拿旧缓存糊弄你**。
这一章把这些一次性做完。

> 配套示例：`examples/tutorial/15_建站.jsh`
> 跑一次生成 `建站示例/` 目录 —— **整个目录传上去就能访问**，不需要后端。

## 15.1 本站的四条规矩

`站点` 模块不是「又一堆函数」，它是四条**已经定死的规矩**：

| 规矩 | 为什么 |
|---|---|
| **可复现**：同样输入生成**逐字节相同**的文件 | 不然每次构建 git 里全是假变更，也看不出「这次到底改了什么」 |
| **样式表名字带内容指纹** | 文件名变了，浏览器才会重新下载；不变就说明内容真没变 |
| **不引框架、不引 CDN** | 断网能用、内网能部署、十年后还能打开 |
| **五个执行器输出逐字一致** | 你换引擎（Python/Rust/C/Node）构建，产物必须一样 |

## 15.2 布局：整站共用的那几项

```jsh
令 布局表 = 站点.布局({
    "标题后缀":"小站",              # <title> 后缀
    "品牌":"小站",
    "品牌副":"demo",
    "导航项":[["index.html", "首页"], ["文章.html", "文章"]],
    "脚注":"由基石生成 · 站点模块示例",
    "网址前缀":"https://例子.cn",   # sitemap 里的绝对前缀，**必须给**
})
```

🔴 **导航项是 `[地址, 文字]`**（地址在前） —— 和上一章 `html.页面` 的
`[文字, 地址]` **正好相反**。这是已知的不一致，反了不报错，只会链接文字变成路径。

没给的键都有默认值，所以最小可用是 `站点.布局({})`（但 `网址前缀` 缺了
sitemap 里的链接就是相对路径，搜索引擎可能不认）。

## 15.3 页面：路径 + 标题 + 正文

```jsh
令 页们 = [
    {"路径": "index.html", "标题": "首页", "正文": 首页正文},
    {"路径": "文章.html", "标题": "文章", "正文": 文章正文},
]
```

正文是 **HTML 片段**（通常用上一章的 `html` 模块拼）。规矩同上一章：
**用户填的东西一律先 `html.转义`**，只有你自己拼好的才 `html.原样`。

`路径` 用相对路径（`文章.html` 而不是 `/文章.html`）：整站要能放在
子目录下（比如 `https://例子.cn/demo/`），写死绝对路径就搬不动了。

## 15.4 先看后写：`渲染` 与 `写站`

```jsh
令 已渲染 = 站点.渲染(页们, 布局表)   # → [[路径, 内容], …]，不落盘
令 统计   = 站点.写站("建站示例", 页们, 布局表)
```

`渲染` 是**纯函数**（给数据、出数据，不碰磁盘），所以能直接测：
「标题有没有进 `<title>`」「导航是不是三项」这类断言都写在它上面 ——
**不用先写一个目录再读回来**。

`写站` 返回统计：

```jsh
统计["页面数"]     # 2
统计["样式文件"]   # style.a1b2c3.css（名字里带内容指纹）
统计["sitemap"]    # sitemap.xml
```

## 15.5 指纹：为什么文件名要变

浏览器（和 CDN）会缓存 `.css`。你改了样式但文件名没变，用户那边**还是旧的** ——
而且他刷新也没用。解法是**把内容算成一个短哈希塞进文件名**：

```jsh
站点.资源指纹("abc")   # → 同样的内容，永远同样的指纹
站点.资源指纹("abd")   # → 改一个字，指纹就变
```

这样：内容没变 → 文件名没变 → 走缓存（快）；内容变了 → 文件名变了 →
自动重新下载（对）。**没有构建指纹的站点，只能靠「不许缓存」兜底，那是另一种浪费。**

## 15.6 传上去

`写站` 出来的目录长这样：

```
建站示例/
  index.html
  文章.html
  style.<指纹>.css
  sitemap.xml
```

**纯静态**：`scp`、FTP、对象存储、GitHub Pages 都行，不需要任何运行时。
这也是 `站点` 和 `窗口`/`HTTP服务端` 的分工：能静态就静态，静态最省事、
最不容易挂。

## 15.7 三个坑

1. **`网址前缀` 少了，sitemap 会变成相对链接** —— 不报错，但搜索引擎可能不收。
2. **`路径` 别以 `/` 开头**（那样整站搬不进子目录），也别带 `..`（会写到上级目录，`写站` 会拒绝）。
3. **两次生成要能逐字节相同**。你自己往正文里塞了时间戳、随机数，这条就破了 ——
   于是每次构建 git 全变、指纹全变、缓存全失效。**要时间就放进文章正文里，别放进模板。**
