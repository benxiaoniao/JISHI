# 第 11 章：数据库——数据存得下、查得到、还能汇总

第 7 章我们用 CSV 记账，跑得很好。但账目一多，CSV 就开始难受：

- 想在**上万行**里找「这个月餐饮花了多少」——只能全读进来再自己循环；
- 两个人同时写——后写的把先写的盖掉；
- 想「按类别汇总」——每次都要写一遍分组累加。

这一章用 `数据库` 模块（底子是 **SQLite**，一个文件一个库，任何 SQLite 工具都能打开）
把这些事变成一句话。

> 配套示例：`examples/tutorial/11_记账数据库.jsh`（能直接跑，跑完自己清理）

## 11.1 三个概念，一句话一个

| 概念 | 基石里的样子 |
|---|---|
| **库** | 一个文件，比如 `账目.db`。`数据库.打开("账目.db")` 给你一个**句柄** |
| **表** | 一类数据，比如「账目」。字段不用写类型（SQLite 是动态类型） |
| **记录** | 一行，在基石里就是**一个字典**：`{"日期": "2026-10-01", "金额分": 850}` |

📌 **句柄就是那串路径文本**。`打开` 返回什么，后面每个函数第一个参数就传什么：

```jsh
导入 数据库
令 库 = 数据库.打开("账目.db")
数据库.建表(库, "账目", ["日期", "类别", "金额分", "备注"])
```

## 11.2 建表：不写类型，自动带 `id`

```jsh
数据库.建表(库, "账目", ["日期", "类别", "金额分", "备注"])
数据库.建索引(库, "账目", ["类别"])      # 按类别查会快很多
```

三件事要知道：

1. **不用写类型**：同一列里放整数、文本都行（SQLite 是动态类型）；
2. **每张表自动带 `id`**（从 1 开始的整数主键）—— 所以字段列表里**别写 `id`**，
   写了会报错（`字段名里不用写 id`）；
3. **重复执行不会出错**：表/索引已经存在就不动它。所以你可以在程序开头直接建表，
   不用先判断「有没有这张表」。

## 11.3 记一笔：插入与批量插入

```jsh
数据库.插入(库, "账目", {"日期": "2026-10-01", "类别": "餐饮", "金额分": 850, "备注": "早餐"})
# → 返回新行的 id（1、2、3…）

数据库.批量插入(库, "账目", [
    {"日期": "2026-10-02", "类别": "餐饮", "金额分": 1500, "备注": "午饭"},
    {"日期": "2026-10-02", "类别": "购物", "金额分": 8990, "备注": "键盘"},
])
# → 返回插了几条
```

`批量插入` 把这些行放在**同一个事务**里：要么全成功，要么全不生效，
而且比一条条插快很多（几百上千条时差别很明显）。

## 11.4 查询：条件、排序、倒序、条数

```jsh
数据库.查询(库, 表名, 条件=空, 排序=空, 倒序=假, 条数=0)
```

四个参数里**条件**最常写错，它是「字段 → 值」的字典：

```jsh
数据库.查询(库, "账目", {"类别": "餐饮"})                  # 类别 = 餐饮
数据库.查询(库, "账目", {"金额分": {">": 5000}})            # 金额分 > 5000
数据库.查询(库, "账目", {"类别": "餐饮", "备注": {"包含": "午"}})  # 两个条件是「并且」
数据库.查询(库, "账目", {"备注": {"非空": 真}})              # 备注不是空
```

⚠️ **比大小要嵌一层**：`{"金额分": {">": 5000}}`，**不是** `{">": 5000}`。
后者会报「表「账目」里没有这些字段：`>`」—— 这句话就是在提醒你「嵌一层」，
顺手还会列出这张表真正有哪些字段：

```
错误 E2005：数值不对（表「账目」里没有这些字段：>）
  提示：它有：id、日期、类别、金额分、备注。比大小要**嵌一层**：{"字段": {">": 100}}
```

排序这几个参数是配合用的：

```jsh
数据库.查询(库, "账目", 空, "id", 真, 3)      # 最新的三笔（按 id 倒序）
数据库.查询(库, "账目", 空, "金额分", 真)      # 从贵到便宜
数据库.查询(库, "账目", 空, "金额分", 假, 5)   # 最便宜的 5 笔
```

📌 **`倒序` 作用在你给的排序字段上**；不给 `排序` 时作用在 `id` 上，
也就是「**最新记的几笔在前**」。

查出来的是什么？**字典列表**，每条是一个字典（带 `id`）：

```jsh
[{'id': 1, '日期': '2026-10-01', '类别': '餐饮', '金额分': 850, '备注': '早餐'}, ...]
```

## 11.5 汇总：一句话算完一组数

```jsh
令 各类 = 数据库.汇总(库, "账目", "类别", "金额分")
# {'餐饮': {'个数': 3, '总和': 4550.0, '平均': 1516.66…, '最大': 2200.0, '最小': 850.0},
#  '交通': {...}, ...}

打印(各类["餐饮"]["总和"])
```

每个组的汇总字典与 `表格.汇总` / `表格.分组汇总` **长得一模一样**
（个数 / 总和 / 平均 / 最大 / 最小）—— 学会一个就会另一个。

📌 组按**第一次出现的顺序**排，不按组名排（组名可能是文本也可能是数字，
排序规则不好统一）。要指定顺序就在程序里自己排。

## 11.6 改与删：返回影响了几行

```jsh
数据库.修改(库, "账目", {"备注": "早餐"}, {"备注": "早餐（豆浆+包子）"})   # → 1
数据库.删除(库, "账目", {"类别": "交通", "金额分": 400})                  # → 1
```

- `修改` 第二个字典是「**要改成什么**」，只有列出来的字段会变；
- 两个都**返回影响的行数**：返回 0 说明条件没匹配上（顺手就能发现「我以为有这条」）。

## 11.7 逃生口：真的要写 SQL

```jsh
数据库.执行(库, "UPDATE 账目 SET 备注 = '手写 SQL' WHERE id = 2")   # 写操作
令 行们 = 数据库.执行查询(库, "SELECT 类别, COUNT(*) AS 笔数 FROM 账目 GROUP BY 类别 ORDER BY MIN(rowid)")
```

平时用不到；遇到「一次更新几千行」「复杂的 JOIN」这类 SQL 更擅长的事，
就从这里出去。`执行查询` 返回的也是字典列表。

## 11.8 五个坑（都是真撞过的）

**① 金额要存「分」，不要存小数。**
浮点存钱，几千笔累加就会差几分。存整数分（25.50 元 → `2550`），显示时再除 100：

```jsh
导入 文本 为 文本库
函数 元(分)：
    返回 文本库.小数位(分 / 100, 2)      # 2550 → "25.50"

整数(精确("25.50") * 100)                # → 2550，用「精确」避开浮点
```

**② `精确小数` 存进库会变成浮点。** SQLite 只有五种存储类，没有十进制类型 ——
`精确("0.1")` 存进去、读回来是浮点 `0.1`。要一分不差，就用上面的「整数分」。

**③ 布尔存进去会变成 1/0。** SQLite 没有布尔类型：`真` 存 1、`假` 存 0，
读回来是**整数**。要判断就写 `如果 行["已完成"] == 1：`。

**④ 整数上限 ±9.2e18。** SQLite 的整数是 8 字节，超了会**明确报错**（不会静默截断）——
比它大的数请存文本。

**⑤ 浏览器试玩页没有数据库。** 网页版（wasm）链不了 SQLite，`导入 数据库` 会报
「这个平台没有内置 SQLite（浏览器试玩页链不了它）」。要跑这一章的代码请用命令行 `jishi`。

## 11.9 完整示例

`examples/tutorial/11_记账数据库.jsh` 把这一章串起来：建表 → 记号几笔 → 查最近的 →
按金额倒序查大额 → 分类汇总 → 改一笔 → 删一笔 → 手写一句 SQL → 关库并清理文件。

```bash
jishi examples/tutorial/11_记账数据库.jsh
```

输出（节选）：

```
新记了 3 笔；一共 5 笔
---- 最近两笔 ----
2026-10-03 餐饮 22.00 元 聚餐
2026-10-02 购物 89.90 元 键盘
---- 分类汇总 ----
餐饮 3 笔，合计 45.50 元，平均 15.17 元
```

跑完 `账目.db` 会被删掉。想留着看，把最后两行注释掉，然后用
[DB Browser for SQLite](https://sqlitebrowser.org/) 打开它 —— 它就是个标准 SQLite 文件。

## 11.10 练习

1. **按月份汇总**：日期存的是 `2026-10-01` 这种文本。用 `{"日期": {"包含": "2026-10"}}`
   当条件，算出这个月花了多少。
2. **加一个「已完成」字段**：存 `真`/`假`，查完提醒自己「读回来是 1/0」。
3. **预算提醒**：汇总后判断总额，超过预算就打印一行「⚠️ 超支了」。
4. **两个库**：`2026.db` 和 `2027.db` —— 试一试同时打开两个库（句柄不同，互不干扰）。

## 11.11 小结

| 想做的事 | 写什么 |
|---|---|
| 打开/关掉库 | `数据库.打开(路径)` / `数据库.关闭(库)` |
| 建表、建索引 | `建表(库, 表名, 字段们)` / `建索引(库, 表名, 字段们)` |
| 插入 | `插入`（一条）/ `批量插入`（一批，一个事务） |
| 查 | `查询(库, 表名, 条件, 排序, 倒序, 条数)` |
| 数一数 | `条数(库, 表名, 条件)` |
| 分组统计 | `汇总(库, 表名, 按, 求和, 条件)` |
| 改 / 删 | `修改` / `删除`（都返回影响行数） |
| 写 SQL | `执行` / `执行查询` |

数据从「一堆文本行」变成「能问问题的库」，后面第 12、13 章会把它接到
表格导出和网页接口上 —— 账目存在库里，报表发出去、页面查得到。
