# 第 10 章：包管理——代码复用与分享（M14）

写了很多函数，想在不同项目里复用？想让别人也能用你的代码？这一章讲基石的
包管理：把代码打包、安装、导入。

## 10.1 什么是「包」

一个基石包就是一个目录，里面有两样东西：

```
某包/
├── 包.json      # 包清单（名字/版本/依赖）
└── 若干 .jsh     # 代码模块
```

`包.json` 长这样：

```json
{
  "名字": "数学工具",
  "版本": "2.0.0",
  "依赖": {"基础库": ">=1.0.0"},
  "描述": "提供立方、平方和"
}
```

- `名字`：包名（唯一）
- `版本`：语义化版本（主.次.修订）
- `依赖`：这个包依赖哪些别的包，以及版本要求
- `入口`：可选，指定「对外的主模块」（不写就执行包内所有 .jsh）

## 10.2 安装包

```bash
jishi 安装 包名 --local-dir 目录          # 从本地目录装
jishi 安装 包名 --local-zip 包.zip        # 从 zip 装
jishi 安装 包名 --from-index 索引.json     # 从远端索引拉包
jishi 列表                                 # 看装了什么
jishi 卸载 包名                            # 卸载
```

安装到哪里？项目 `.jishi/packages/`（或用户目录 `~/.jishi/packages/`）。

## 10.3 导入包

装好后，代码里这样用：

```jsh
导入 数学工具 从 本地包
打印(数学工具.立方(3))    # 27
```

## 10.4 依赖是怎么生效的

如果 `数学工具` 声明了依赖 `基础库 >=1.0.0`，那么：

1. 导入 `数学工具` 时，会**自动先加载 `基础库`**
2. 校验 `基础库` 的版本满足 `>=1.0.0`（不满足报中文错）
3. 把 `基础库` 注入到 `数学工具` 的命名空间——所以 `数学工具` 的代码里
   能直接写 `基础库.平方(x)`，不用再 `导入 基础库`

如果出现「甲依赖乙、乙依赖甲」的循环，会直接报
「检测到循环依赖：甲 → 乙 → 甲」。

## 10.5 一个完整示例

`examples/packages/` 里有一个现成示例：`基础库`（提供翻倍/平方）+ `数学工具`
（依赖基础库，提供立方/平方和）。三步跑起来：

```bash
jishi 安装 基础库   --local-dir examples/packages/基础库
jishi 安装 数学工具 --local-dir examples/packages/数学工具
```

然后：

```jsh
导入 数学工具 从 本地包
打印(数学工具.立方(3))          # 27
打印(数学工具.平方和([1, 2, 3])) # 14
```

## 10.6 小结

- 包 = 目录（含 包.json + .jsh）
- `jishi 安装/卸载/列表` 管理包，装到 `.jishi/packages/`
- `导入 X 从 本地包` 使用包
- 依赖自动递归加载 + 版本校验 + 循环检测

到这里，你已经学完了基石的全部核心特性。恭喜！🎉
