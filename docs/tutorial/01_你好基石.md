# 第 1 章：你好，基石

欢迎来到「基石」——一门像 Python 一样简单易用的中文编程语言。
你不需要任何编程基础，只要会打字，就能跟着本教程写出能运行的程序。

## 1.1 运行基石

基石目前通过命令行使用。在终端（命令提示符）里进入项目目录后，输入：

```bash
python -m jishi.cli
```

你会看到：

```
基石 jishi 0.1.0 —— 一门像 Python 一样简单易用的中文编程语言
输入「退出」离开；冒号结尾的行会继续输入（多行代码块）。

基石>
```

这个 `基石>` 就是交互式界面（REPL）：你敲一行代码，它立刻执行一行。
输入 `退出` 可以离开。

## 1.2 第一个程序：打印

在 `基石>` 后面输入：

```python
打印("你好，世界")
```

按回车，屏幕上会出现：

```
你好，世界
```

`打印` 是基石最常用的函数，作用是把内容显示到屏幕上。
引号里的文字叫**字符串**（文本）。注意：打印的内容可以不带引号（比如数字），
但**文本一定要用引号包起来**。

试试这些：

```python
打印(1 + 1)          # 输出 2
打印("1 + 1")        # 输出 1 + 1（带引号是文本，不是计算）
打印(3.14)           # 输出 3.14
```

## 1.3 变量：给值起名字

**变量**就像贴了标签的盒子，可以把值装进去，之后用名字来引用它。
用 `令` 来创建变量：

```python
令 名字 = "小明"
令 年龄 = 12
打印(名字)          # 输出 小明
打印(年龄)          # 输出 12
```

`令` 是"声明变量"的意思，`=` 表示"把右边的值装进左边的盒子"。
之后你可以随时改变量的值：

```python
年龄 = 13            # 不用再写令，直接赋值
打印(年龄)          # 输出 13
```

变量名用什么都可以，中英文都行（中文是基石的特色！）：

```python
令 我的宠物 = "猫"
令 猫的数量 = 2
打印(我的宠物, "有", 猫的数量, "只")
```

## 1.4 注释：写给自己的笔记

以 `#` 开头的一行是**注释**，用来解释代码在做什么。注释不会被执行：

```python
# 这是一条注释，计算机看到它会直接跳过
打印("注释很重要")    # 行尾也可以写注释
```

写注释是良好的习惯——尤其是几个月后再回来看代码的你。

## 本章小结

- `打印(...)` 把内容显示到屏幕
- 文本要用引号 `"..."` 包起来
- `令 名字 = 值` 创建变量，之后直接 `名字 = 新值` 修改
- `#` 开头是注释，不执行
