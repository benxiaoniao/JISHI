# 第 13 章：HTTP 服务端——给数据起一个能用的接口

前两章把账存进了数据库、把成绩写成了 Excel。这一章让它们**能被访问**：
在浏览器里打开一个地址，就看到数据。

> 配套示例（两个文件）：
> - `examples/tutorial/13_HTTP接口.jsh` —— **纯函数**那一半，不起服务也能跑（推荐先看）
> - `examples/tutorial/13_HTTP服务.jsh` —— 真起一个服务，浏览器能打开

## 13.1 四个零件 + 一张路由表

| 函数 | 干什么 | 要 socket 吗 |
|---|---|---|
| `HTTP服务端.解析请求(原文)` | 一段原始请求文本 → 请求字典 | 不要（纯函数） |
| `HTTP服务端.构造响应(状态, 正文, 内容类型, 头)` | 状态 + 正文 + 头 → 一段完整响应文本 | 不要（纯函数） |
| `HTTP服务端.启动(端口, 处理函数, 最多请求数)` | **阻塞**着收请求，每个请求调一次处理函数 | **要** |
| `HTTP服务端.空闲端口()` | 问系统要一个当前空闲的端口 | **要** |

路由单独一个模块（`HTTP路由`）：`路由表()` → `加路由(表, 方法, 路径, 处理)`，
用的时候 `匹配(表, 方法, 路径)`。

## 13.2 一次请求长什么样

HTTP 请求就是**一段文本**：

```
POST /提交 HTTP/1.1
Host: 127.0.0.1
Content-Type: application/json

{"a":1}
```

`解析请求` 把它变成字典：

```jsh
令 请求 = HTTP服务端.解析请求("GET /查?a=1&b=%E4%BD%A0 HTTP/1.1\r\n\r\n")
# {'方法': 'GET', '路径': '/查', '查询': {'a': '1', 'b': '你'},
#  '版本': 'HTTP/1.1', '请求头': {}, '正文': ''}
```

两条约定：

- **请求头的名字统一小写**（`Content-Type` → `content-type`）—— HTTP 头名本来不分大小写；
- **查询参数**（`?a=1&b=…`）已经解好 `%XX`，直接 `请求["查询"]["a"]`。

## 13.3 处理函数：进「请求 + 路径参数」，出一段响应文本

```jsh
函数 查某人(请求, 参数)：
    遍历 人 在 成绩们：
        如果 人["姓名"] == 参数["姓名"]：
            返回 HTTP服务端.构造响应(200, json.转文本(人),
                                     "application/json; charset=utf-8")
    返回 HTTP服务端.构造响应(404, json.转文本({"错": "没有这个学生"}))
```

- 第一个参数是**请求字典**（要不要用随你）；
- 第二个是**路径参数**（路由里 `:名字` 那几段）；
- 返回值必须是**一段完整的响应文本** —— 用 `构造响应` 拼，别自己手写。

响应长这样（`构造响应` 自动补 `Content-Length` 与 `Connection: close`）：

```
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Content-Length: 6
Connection: close

你好
```

📌 `Content-Length` 数的是**字节**不是字符：`你好` 是 2 个字符、**6 个字节**。
这件事模块替你算了，但这也说明了下面那条坑。

## 13.4 路由表：哪条路走哪个函数

```jsh
令 表 = HTTP路由.路由表()
HTTP路由.加路由(表, "GET", "/", 首页)
HTTP路由.加路由(表, "GET", "/成绩/:姓名", 查某人)     # `:姓名` 匹配任意一段
HTTP路由.加路由(表, "GET", "/排行", 排行)

打印(HTTP路由.路径们(表))    # ['GET /', 'GET /成绩/:姓名', 'GET /排行']
```

规则（三条宿主完全一致）：

| 情形 | 行为 |
|---|---|
| 路径 | 按 `/` 切段逐段比；**末尾斜杠严格区分**（`/a` 与 `/a/` 是两条路） |
| 参数段 | 以 `:` 开头的段匹配**任意一段**，值进 `参数`；**空段不算**（`/成绩/` 匹配不上 `/成绩/:姓名`） |
| 方法 | **大写后**比较（`get` 就是 `GET`）；写 `"*"` 表示什么都收 |
| 没命中 | `匹配` 返回 **`空`**，不抛错 —— **404 是正常流程**，不是异常 |

## 13.5 先别起服务：纯函数也能测（这一节最重要）

`解析请求` / `构造响应` / `路由表` **都不碰 socket**。所以整个接口逻辑可以当普通函数测：

```jsh
函数 走一遍(方法, 目标)：
    令 原文 = 方法 + " " + 目标 + " HTTP/1.1\r\nHost: 127.0.0.1\r\n\r\n"
    令 请求 = HTTP服务端.解析请求(原文)          # 自造一个请求
    令 命中 = HTTP路由.匹配(表, 请求["方法"], 请求["路径"])
    如果 命中 == 空:
        返回 HTTP服务端.构造响应(404, "没有这一页")
    返回 命中["处理"](请求, 命中["参数"])        # 调你的处理函数

打印(走一遍("GET", "/成绩/小明"))
打印(走一遍("GET", "/成绩/不存在"))
打印(走一遍("GET", "/排行?前=2"))
```

`examples/tutorial/13_HTTP接口.jsh` 就是这么写的，输出：

```
GET /成绩/小明 → HTTP/1.1 200 OK ｜ {"姓名": "小明", "语文": 92, "数学": 88}
GET /成绩/不存在 → HTTP/1.1 404 Not Found ｜ {"错": "没有这个学生"}
GET /排行?前=2 → HTTP/1.1 200 OK ｜ [{"名次": 1, "姓名": "小红", "总分": 182}, …]
GET /没有这个路径 → HTTP/1.1 404 Not Found ｜ 没有这一页
POST / → HTTP/1.1 404 Not Found ｜ 没有这一页
```

📌 **为什么值得这么写**：
① 改一行就重跑，不用开浏览器点；
② 五个执行器都能跑（`启动` 不是）；
③ 以后加「单元测试」也是在同一个口子上。

## 13.6 真起服务

```jsh
函数 处理(请求):
    令 命中 = HTTP路由.匹配(表, 请求["方法"], 请求["路径"])
    如果 命中 == 空:
        返回 HTTP服务端.构造响应(404, "没有这一页")
    返回 命中["处理"](请求, 命中["参数"])

HTTP服务端.启动(8000, 处理)
```

跑 `jishi examples/tutorial/13_HTTP服务.jsh`，然后浏览器打开 `http://127.0.0.1:8000`，
或者 `curl http://127.0.0.1:8000/成绩/小明`。

`启动` 的三个参数：

| 参数 | 说明 |
|---|---|
| 端口 | `0` = 让系统分一个空闲的（**实际端口在返回值里**）；`8000` 这种要自己保证没被占 |
| 处理函数 | 每个请求调一次 |
| 最多请求数 | `0`（默认）= **一直跑**，Ctrl-C 停；给个正数 = 处理够这么多就**干净退出** |

返回 `{"端口": 实际端口, "请求数": 收到几个}`。
⚠️ `请求数` 数的是**真正被处理函数处理过的**请求 —— 连上就断的空连接（端口探测、健康检查）不算。

📌 **示例里给了 10**（`启动(8000, 处理, 10)`）：这样演示完自己会退出、也能被自动化测试。
想一直开着就删掉第三个参数。

## 13.7 边界：不是每个平台都能起服务

| 平台 | 能起吗 |
|---|---|
| Python / Rust / C VM（命令行 `jishi`） | ✅ |
| **Node 宿主** | ❌ 明确报错 |
| **浏览器试玩页（wasm）** | ❌ 明确报错 |

Node 的报错原文：

```
这个平台起不了 HTTP 服务端：Node 宿主是**同步**的，而 `node:http` 要事件循环
（没有「同步泵事件循环」的 API，阻塞住了处理函数永远等不到）
```

**为什么**：`node:http` 是异步 + 事件循环，而基石的 VM 是同步的 —— 真阻塞住事件循环就跑不动，
除非把服务端塞进子进程，那又调不到你的基石函数了。取舍见 D81。
📌 **纯协议那一半（解析/构造/路由）在 Node 上照样能用** —— 所以 §13.5 那套写法是跨平台的。

## 13.8 五个坑

**① 内容类型必须带 `charset=utf-8`，否则中文乱码。**
浏览器拿不到 `charset` 时会按本地编码猜（Windows 上常是 GBK）：

```jsh
HTTP服务端.构造响应(200, 页, "text/html; charset=utf-8")     # 别只写 "text/html"
```

**② 返回值必须是「整段响应」，不是正文。** 处理函数返回 `"你好"` 这种裸文本，
浏览器会拿到报错。永远用 `构造响应` 包一层。

**③ 末尾斜杠严格区分。** `/成绩/小明` 与 `/成绩/小明/` 是两条路，后者没注册就是 404。

**④ 处理函数抛异常 → 回 500，服务继续。** 这是故意的：一条坏请求不该让本地服务整个挂掉，
而且浏览器里能直接看到那行错误 —— 正文就是错误的第一行，例如：

```
HTTP/1.1 500 Internal Server Error
...
错误 E2001：不能除以零
```

所以**别把「会崩」当成可以忽略的设计**：它确实不崩，但用户看到的是一片 500。

**⑤ 只监听本机（`127.0.0.1`），这是安全默认。** 别人连不上你的电脑。
要给别人访问，得换正经的部署方式（反向代理 / 云服务器），不是把监听地址改成 `0.0.0.0`
—— 那等于把调试接口暴露到局域网。

## 13.9 完整示例

```bash
jishi examples/tutorial/13_HTTP接口.jsh     # 纯函数，秒级跑完
jishi examples/tutorial/13_HTTP服务.jsh     # 真服务，浏览器打开 127.0.0.1:8000
```

服务版跑起来后：

```
服务已起：http://127.0.0.1:8000   （Ctrl-C 停）
...
服务已停：共处理 10 个请求（端口 8000）
```

三条路：`/`（首页 HTML）、`/成绩/:姓名`（一个人，JSON）、`/排行`（总分排行，JSON）。

## 13.10 练习

1. **加一条路**：`/班级/:班` —— 按班级过滤，返回 JSON 列表。
2. **分页**：`/排行?前=2&从=1` —— 用 `请求["查询"]` 的两个参数切一段。
3. **接数据库**：把第 11 章的 `数据库.查询` 搬进处理函数，接口返回数据库里的账目。
4. **错误页**：让 404 返回一段好看的 HTML 而不是一句话。

## 13.11 小结

| 想做的事 | 写什么 |
|---|---|
| 解析一段请求 | `HTTP服务端.解析请求(原文)` |
| 拼一段响应 | `HTTP服务端.构造响应(状态, 正文, 内容类型)` |
| 注册路由 | `HTTP路由.加路由(表, 方法, 路径, 处理)` |
| 找处理函数 | `HTTP路由.匹配(表, 方法, 路径)`（没命中给 `空`） |
| 起服务 | `HTTP服务端.启动(端口, 处理函数, 最多请求数)` |

到这里，0.2.10 的三篇教程（数据库 / Excel / HTTP）就补齐了：
**存得下 → 发得出去 → 别人能访问**。
