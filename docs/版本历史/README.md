## 为什么有这一块

2026-10-08：架构变革（前后端分层、前端换 Rust、单二进制、wasm）把项目整个换了一遍，
**旧的文档里有一大批已经不再适合当参考**了：

- 有些是**已被抛弃的路径**（0.1.x 时期的规划、当时准备砍/留的评估）；
- 有些是**决策已经落地、只剩余味**（评估类文档——结论已经写进代码和设计决策里）；
- 有些是**流水账**（每一步交付的明细）。

把它们留在主线文档里有两个坏处：**读的人被历史淹没**（README 的「当前进度」曾
占 600 多行），**以及拿过时结论去判断现在**。所以集中到这里，**留个地方给这些材料**，
既不假装它们不存在（这是这个语言的历史），也不让它们影响当下的判断。

## 几条使用须知

- **别在本目录里改内容**。「历史不改写」是这个项目的规矩 —— 发现原文有误，
  在**当前**文档里更正，并在这里保留原文。
- 原文里的**内部链接可能已经失效**（文件被搬过、章节被裁过）。需要追溯时按
  文件名在仓库里搜。
- ⚠️ 本目录里有**几份不上传到公开仓库**（含自建分发服务器的实例信息 / 未定稿决策）
  —— 名单以 `tools/publish_github.py` 的 `INTERNAL_DOCS` 为准。
  🔴 **移动 / 改名本目录里的文件时要同步改那里的排除规则**：它是**按路径匹配**的，
  2026-10-08 才从「非递归」改成递归 —— 漏了这条就是**把服务器信息推到公开仓库**。
