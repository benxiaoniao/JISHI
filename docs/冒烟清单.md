# 发行版冒烟清单（M16.4）

发布前，每项都要在**干净机器**（无 Python 环境）上人工验证一次。
按顺序勾选，任何一项失败即阻断发布。

## 验证环境

- [ ] 机器类型：Windows x64（干净，无 Python）
- [ ] 下载产物：`jishi-0.1.0-windows-x64.zip` + `SHA256SUMS`
- [ ] 校验哈希：`Get-FileHash ... -Algorithm SHA256` 与 SHA256SUMS 一致

## 冒烟步骤

1. [ ] **解压**：解压 zip，看到 `bin/`、`share/`、`install.ps1`、`uninstall.ps1`、`README.md`
2. [ ] **安装**：`powershell -ExecutionPolicy Bypass -File install.ps1`
   - 提示「已把 ~/.jishi/bin 加入用户 PATH」
   - 自检输出 `基石 jishi 0.1.0`
3. [ ] **新开终端**（验证 PATH 生效）：`jishi --version` 正确输出版本号
4. [ ] **跑 hello**：写 `hello.jsh`（`打印("你好")`），`jishi hello.jsh` 输出「你好」
5. [ ] **离线语言卡**：`jishi --ai-card` 输出语言卡（不依赖源码树）
6. [ ] **JSON 报错自愈**：写个错误脚本，`jishi 错.jsh --json-errors`
   输出含 `fix` 字段
7. [ ] **沙箱**：`jishi 脚本.jsh --sandbox --json-result` 输出统一协议 JSON
8. [ ] **包管理**：`jishi 列表` 能运行；`jishi 新项目 测试` 生成脚手架
9. [ ] **医生自检**：`jishi 医生` 全部 ✅（含 C VM 加载成功）
10. [ ] **MCP**：`jishi-mcp` 能被 MCP 宿主识别并跑通 `run_script`
11. [ ] **卸载**：`powershell -ExecutionPolicy Bypass -File uninstall.ps1`
    - `~/.jishi` 被删除，用户 PATH 恢复，`jishi` 命令失效

## 已知限制（需在发布说明如实告知，不视为失败）

- 发行包体积约 30-60MB（内含 Python 运行时）
- PyInstaller 产物可能被杀软误报（提供 wheel / 源码两条替代途径）
- 冷启动略慢于纯 Python（onedir 已缓解）

## 诚实边界

- 本机只能直接构建 + 验证 **Windows x64** 版
- Linux 版依赖 CI 容器构建；macOS 版若 CI 能力不足则延后，不假装三平台齐备
