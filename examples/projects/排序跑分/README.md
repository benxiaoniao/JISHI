# 排序跑分（算法练习）

用基石写的三个排序实现 + 跑分表：**正确性用内建 `排序()` 当裁判**，
耗时用 `时间.高精度时间()` 量——把课本上的复杂度符号变成表里的数字。

## 用法

```bash
jishi examples/projects/排序跑分/排序.jsh        # 默认规模 100 / 200 / 400
jishi examples/projects/排序跑分/排序.jsh 800    # 指定规模
```

## 输出示例

```
== 排序跑分 ==
每种排序各跑一遍，随机整数数据；正确性用内建「排序()」当裁判。

规模    冒泡(毫秒)     插入(毫秒)     快速(毫秒)
----------------------------------------
100     48.15          26.69          5.02
200     176.11         102.0          10.98
400     694.71         390.34         26.22

三个排序的结果都与内建排序一致 ✅
```

（数字随机器变化，看的是**趋势**：冒泡/插入大致 4 倍增长，快速约 2.4 倍。）

## 用到的语言特性

- 递归（快排）、列表推导式（分两半）、`遍历`/`当`/`中断`
- `随机.随机整数`、`时间.高精度时间`、`**` 幂运算、`整数()`
- 元组式解包（`令 用时, 结果 = 耗时(...)`）
- 用内建 `列表.排序()` 给自写排序当**裁判**——正确性不能靠自己说了算

## 两个已知的不顺手处（已记进别扭点清单）

- **下标目标不能解包赋值**：冒泡交换写的是三行（临时变量），
  `结果[j], 结果[j+1] = 结果[j+1], 结果[j]` 解析不过。
- **缺 `round`**：表格里的小数位得自己写（`整数(x*100+0.5)/100`），
  Python 一个 `round(x, 2)` 就够。
