# 网页采集工具

用基石写的真实网页采集脚本：抓取一个网页，用正则提取所有链接（标题 + 网址），
保存成 CSV，并统计链接总数。

## 用法

```bash
jishi examples/projects/网页采集/采集.jsh
```

运行后输入目标网址（如 `https://example.com`），脚本会：
1. 用 `网络.获取` 抓取网页 HTML
2. 用 `正则.查找全部` 提取所有 `<a href="...">标题</a>`
3. 用 `表格.写表格` 存成 `链接.csv`
4. 打印链接总数和去重后的域名分布

## 用到的语言特性

- `网络`（获取 GET）、`正则`（查找全部/替换）、`表格`、`文件`
- 列表推导式、字典频次统计、`尝试/捕获`（网络失败兜底）
