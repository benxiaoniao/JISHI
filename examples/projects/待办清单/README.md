# 待办清单（CLI 工具）

用基石写的命令行待办工具：增删改查 + JSON 持久化 + 命令行参数。
数据存在同目录的 `待办.json` 里。

## 用法

```bash
cd examples/projects/待办清单
jishi 待办.jsh 列出
jishi 待办.jsh 添加 买牛奶
jishi 待办.jsh 添加 写周报 修自行车      # 多个词会拼成一条
jishi 待办.jsh 完成 2
jishi 待办.jsh 取消完成 2
jishi 待办.jsh 删除 1
jishi 待办.jsh 清空已完成
```

## 输出示例

```
$ jishi 待办.jsh 添加 买牛奶
已添加第 1 条：买牛奶

$ jishi 待办.jsh 完成 1
第 1 条现在：买牛奶（完成）

$ jishi 待办.jsh 列出
== 待办清单 ==
  [√] 1. 买牛奶
  [ ] 2. 写周报 修自行车

共 2 条：已完成 1，未完成 1
```

出错时给人话，不甩栈：

```
$ jishi 待办.jsh 完成 abc
「abc」不是序号——序号是数字，例如 3

$ jishi 待办.jsh 完成 9
清单里没有第 9 条（共 2 条）
```

## 用到的语言特性

- `系统.参数()`（命令行参数）、`json`（读文件/写文件）
- `文件.文件存在`、字典增删、`列表.追加/弹出`
- f-string 插值、条件表达式 `甲 如果 条件 否则 乙`
- `尝试/捕获`：**注意这里捕获的是「异常」**——按 Python 直觉 `int("abc")` 该是
  `值错误`，基石现在抛的是「类型错误」，这条已记进 `docs/真实项目.md` 别扭点清单
