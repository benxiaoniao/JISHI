# CSV 成绩分析工具

用基石写的真实数据处理工具：读一个带「姓名,语文,数学,英语」表头的 CSV，
输出总分排名、各科平均分、最高分与不及格名单。

## 用法

```bash
jishi examples/projects/成绩分析/分析.jsh
```

运行后按提示输入 CSV 文件路径（默认 `成绩.csv`，可用下方样例数据）。

## 样例数据

准备一个 `成绩.csv`（UTF-8，第一行表头）：

```csv
姓名,语文,数学,英语
小明,92,88,95
小红,85,90,78
小刚,60,55,72
小丽,98,96,99
```

## 输出示例

```
== 成绩分析 ==
共 4 名学生

总分排名：
  1. 小丽 293 分
  2. 小明 275 分
  ...

各科平均：语文 83.75、数学 82.25、英语 86.0

不及格名单：小刚（数学 55）
```

## 用到的语言特性

- `表格` 标准库（读表格/挑选/排序按/汇总）
- `文本` 标准库（拼接/格式化）
- 列表推导式、字典、`遍历`、`输入()` 交互、`尝试/捕获` 容错
