# 小网站 —— 用 `HTTP服务端` + `HTTP路由` 写的第一站

跑起来：

```bash
jishi 网站.jsh
```

然后在浏览器打开 <http://127.0.0.1:8000/>，或者用命令行看：

```bash
curl http://127.0.0.1:8000/
curl http://127.0.0.1:8000/文章/1
curl http://127.0.0.1:8000/没有这个
```

按 `Ctrl-C` 停。

## 这个例子想说明什么

1. **路由就是一张表**（`路由表()` → `加路由` → `匹配`），没有隐藏机制；
2. **404 不是异常**：`匹配` 没命中返回 `空`，你自己决定怎么回；
3. **404 页把「有哪些路」列出来** —— 网址写错时，这一句比「没有这一页」有用得多；
4. **只监听本机**（`127.0.0.1`）：局域网里的手机连不上，这是安全默认。

## 已知边界（如实说）

- **没有模板引擎**：HTML 是字符串拼的。拼复杂页面会很啰嗦 ——
  这块在 0.2.7 再看（内部路线图（未公开） §12.16）。
- **没有中间件**：日志、鉴权、静态文件都得自己写在处理函数里。
- **一问一答就关**（`Connection: close`）：本地小站够用，不适合上生产。
- 一次只能处理一个请求（同步模型）—— 所以**别用它扛并发**。
