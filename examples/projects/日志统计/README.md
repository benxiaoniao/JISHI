# 日志统计工具

用基石写的真实日志分析工具：读一个服务器访问日志（每行一条），统计
访问量、独立 IP 数、各状态码分布、访问最多的路径 Top5。

## 用法

```bash
jishi examples/projects/日志统计/统计.jsh
```

运行后输入日志文件路径（默认 `访问.log`）。

## 样例日志格式

```
192.168.1.1 - GET /首页 200
192.168.1.2 - POST /登录 200
192.168.1.1 - GET /图片/logo.png 404
192.168.1.3 - GET /首页 200
192.168.1.2 - GET /关于 301
```

即：`IP 方法 路径 状态码`（空格分隔，方法前有个 `-` 占位）。

## 输出示例

```
== 日志统计 ==
总请求数：5
独立 IP 数：3

状态码分布：
  200：3 次
  404：1 次
  301：1 次

访问最多的路径：
  /首页：2 次
  /图片/logo.png：1 次
  ...

404 请求的 IP：
  192.168.1.1
```

## 用到的语言特性

- `用 打开(…) 为 f：` 上下文管理器（M26：块结束自动关文件，流式按行遍历）、
  `文本.拆分`、列表推导式
- 字典频次统计、`排序按`（或字典排序）、`遍历`
- `尝试/捕获` 容错、字符串插值
