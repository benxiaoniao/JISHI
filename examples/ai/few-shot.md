# 基石（jishi）few-shot 示例库

20 个「任务描述 → 基石代码」精炼对，覆盖高频场景。
用于 few-shot 提示：把前几个示例贴进 LLM 上下文，再给出新任务。

---

## 示例 1：计算平均值
**任务**：写函数计算列表平均值。
```jsh
函数 平均值(数据):
    返回 总和(数据) / 长度(数据)
```

## 示例 2：过滤正数
**任务**：从一个列表里筛出所有正数。
```jsh
令 正数 = [x 遍历 x 在 数据 如果 x > 0]
```

## 示例 3：统计频次
**任务**：统计列表里每个元素出现的次数。
```jsh
令 频次 = {}
遍历 x 在 数据:
    如果 频次.包含(x):
        频次[x] += 1
    否则:
        频次[x] = 1
```

## 示例 7：判断素数
**任务**：写函数判断一个数是不是素数。
```jsh
函数 是素数(n):
    如果 n < 2:
        返回 假
    遍历 i 在 范围(2, n):
        如果 n % i == 0:
            返回 假
    返回 真
```

## 示例 8：类与对象
**任务**：定义一个银行账户类，支持存款取款。
```jsh
类 账户:
    函数 初始化(自身, 余额):
        自身.余额 = 余额
    函数 存(自身, 数额):
        自身.余额 += 数额
    函数 取(自身, 数额):
        如果 数额 > 自身.余额:
            抛出 值错误("余额不足")
        自身.余额 -= 数额

令 我的 = 新建 账户(100)
我的.存(50)
```
