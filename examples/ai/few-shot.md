## 示例 29：闭包
**任务**：写一个能记住累加状态的计数器。

内层函数里给外层变量赋值算「新建局部变量」（M40 起与字节码执行器一致，
也和 Python 一样），所以计数器要把状态放在**可变容器**里：
```jsh
函数 造计数器():
    令 状态 = [0]
    函数 加一():
        状态[0] = 状态[0] + 1
        返回 状态[0]
    返回 加一
令 计 = 造计数器()
打印(计(), 计(), 计())            # 1 2 3
```
