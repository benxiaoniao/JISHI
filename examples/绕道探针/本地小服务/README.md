# 本地小服务（绕道探针）

需求很日常：**给「待办清单」加个网页界面** —— 浏览器里点一下、加一条。

状态：已毕业（M115 起绕道为 0）

⚠️ 它属于 `examples/绕道探针/` —— 原来是「量尺」：这条撞得最狠，
**语言当初完全没有「服务端」能力**，所以它写出来的不是服务，是**静态页的近似品**。
撞出来的每一处都记在下面的「绕道清单」里，由 `tools/detour_ledger.py`
汇总成 `docs/绕道台账.md`。

📌 **M115（`HTTP服务端`）把 R006 消掉了** —— 于是它不再是量尺，
而是「新能力怎么用」的示范。标记就是上面那行 `状态：已毕业`：
判据两边都盯着（没标的必须至少一条绕道，**标了的必须一条都没有**）。

## 用法

```bash
jishi examples/绕道探针/本地小服务/服务.jsh            # 只打用法（**不阻塞**）
jishi examples/绕道探针/本地小服务/服务.jsh 0          # 自动挑空闲端口，一直跑
jishi examples/绕道探针/本地小服务/服务.jsh 8000       # 指定端口，一直跑
jishi examples/绕道探针/本地小服务/服务.jsh 8000 3     # 收 3 个请求就干净退出
```

跑起来后**在浏览器里打开它打印的那个地址**（`http://127.0.0.1:端口/`）：
列表 + 一个输入框，点「加上」就加一条、点「删」就删一条，内容落在同目录的 `待办.json`。

⚠️ **只在 `127.0.0.1` 上监听** —— 局域网里的手机连不上，这是**安全默认**。
⚠️ 无参数时**只打用法就退出**：探针会被 `check_engines` / `conformance` 自动跑，
真起一个阻塞的服务端会把判据**挂死**（M115 踩到过）。

## 它原来差在哪（M115 之前）

当时生成出来的不是服务，是一张静态页：

```html
<!doctype html>
<html>
<meta charset="utf-8" />
<title>待办</title>
<h1>待办清单</h1><ul><li>买菜</li><li>写周报</li><li>给猫铲屎</li></ul>
</html>
```

**它不能点。** 改完待办要重新跑一遍程序、再手动刷新页面。
差别不在「写得好不好」，而在**没有入口**：没有 socket、没有 HTTP 服务端，
就没办法「等着浏览器来请求」。

## M115 之后：它是个**真的服务端**了

页面上的表单真的会提交到 `/加`，处理函数收到请求、改完 `待办.json`、
回一个 303 让浏览器跳回首页 —— 和 `参考实现.py`（Python 的 `http.server`）**同一件事**。

三条约定（`docs/设计决策.md` **D81** 有完整论证）：

| 约定 | 为什么 |
|---|---|
| 只监听 `127.0.0.1` | 安全默认；要对外就自己套一层反向代理 |
| **一问一答就关**（`Connection: close`） | 本地小服务够用，且「一个请求 = 一次处理函数调用」最好推理 |
| 正文按 UTF-8 | 不合法字节替换成 ``；要传二进制先 `编码.base64编码` |

## 用到的语言特性

- `HTTP服务端`（`启动` / `解析请求` / `构造响应` / `空闲端口`）
- `html`（`标签` / `无序列表` / `空元素` + 属性）、`json`、`文件`、`文本`、`系统`
- 函数作参数传给标准库（`HTTP服务端.启动(端口, 处理, 上限)` —— 处理函数是**基石函数**）
- 字符串转义（`\n`、`\"`）与跨行字符串拼接、条件表达式
