# 本地小服务（绕道探针）

需求很日常：**给「待办清单」加个网页界面** —— 浏览器里点一下、加一条。

⚠️ 它属于 `examples/绕道探针/` —— **不是教学示例，是「量尺」**。
这条撞得最狠：**语言现在完全没有「服务端」能力**，所以下面写出来的
不是服务，是**静态页的近似品**。撞出来的每一处记在下面的清单里。

## 用法

```bash
jishi examples/绕道探针/本地小服务/服务.jsh
```

它在**当前目录**生成 `待办.html`（读同目录的 `待办.json`，没有就用三条默认的）。

## 它到底差在哪

生成出来的页长这样（真的是这段 HTML）：

```html
<!doctype html>
<html>
<meta charset="utf-8" />
<title>待办</title>
<h1>待办清单</h1><ul><li>买菜</li><li>写周报</li><li>给猫铲屎</li></ul>
</html>
```

**它不能点。** 改完待办要重新跑一遍程序、再手动刷新页面。
差别不在「写得好不好」，而在**没有入口**：没有 socket、没有 HTTP 服务端，
就没办法「等着浏览器来请求」。

对照 `参考实现.py`（Python，20 来行）：`http.server` 起一个真服务，
页面上一个表单，点一下就加一条 —— 同样的需求，那边是**活的**。
