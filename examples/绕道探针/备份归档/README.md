# 备份归档探针

状态：已毕业（M118 起绕道为 0）

「按日期打包产物、给清单签名、把日志压成 `.gz`」——一个真实的小备份工具。

这是 **M109「时间 + 余项」**（日期时间 / 加密 / 压缩）的量尺：只用手上的
标准库尽力写，写不顺手的地方就是缺口。M109 之前它撞出 6 条，**M109 之后
消掉 5 条**，只剩下面这一条。

## 用法

```bash
cd "examples/绕道探针/备份归档"    # 在探针目录里跑，产物写当前目录的 归档/
jishi 备份.jsh
jishi 备份.jsh 我的口令            # 换个口令（影响签名与口令摘要）
```

`样本/` 是准备好的输入：两个 `.log`（第一行带 ISO 时间戳）、一个 `.md`、
一个 `.csv`。跑完 `归档/` 里有：`备份-<今天>.zip`（整箱）、`日志.gz`
（单文件压缩）、`清单.txt`（每条带 sha256）、`口令.txt`（盐 + 口令摘要）。

📌 **M118 把最后一条（R301）也消掉了** —— 于是它不再是量尺，而是
「新能力怎么用」的示范：`压缩.解压成员(箱子, 成员名)` 只取出那一件。

## 已消掉的绕道（记在这里，台账里不再列）

| 原编号 | 撞到的 | M109 怎么修的 |
|---|---|---|
| R301 | 只看箱子里的一份文件 —— `解压` 会把整棵树铺到磁盘上 | **M118**：新增 `压缩.解压成员(包路径, 成员名)`，在内存里取一件 |
| R302 | 日期只能按天加减，算「每月一次」会越错越远（`加天数(30)`） | 新增 `日期.加月(月数, 日期)` / `日期.加年(年数, 日期)`（**月末自动收**：`1月31日 + 1月 = 2月28日`） |
| R303 | 日志第一行是 ISO 时间戳（`2026-10-12T08:30:00Z`），取不出日期 | 新增 `日期.解析ISO(文本)` —— 认 `T`/空格/毫秒/`Z`/`±HH:MM`，**按字面取日期**（不做时区换算） |
| R304 | 单文件压缩没有入口（只有 zip 的打包/解压） | 新增 `压缩.压缩文件(gz路径, 内容)` / `压缩.解压文件(gz路径)`（`.gz` 单流） |
| R305 | 只有摘要，没有**带密钥**的签名 —— 摘要谁都能重算，挡不住改 | 新增 `加密.HMAC(键, 文本, 算法="sha256")` |
| R306 | 存口令只能存明文（摘要不加盐，同一个口令到哪都是同一个摘要） | 新增 `加密.口令摘要(口令, 盐, 迭代=10万, 算法="sha256")`（PBKDF2）+ `加密.安全随机字节(长度)`（取系统熵源做盐） |

📌 **M113（`字节` 值类型）顺着本探针还清了一笔**：R306 加的 `安全随机字节`
当时**返回的是十六进制文本**（基石没有字节类型，二进制只能拿文本凑合）——
名字里带「字节」却给文本，是本探针留下的**最刺眼的一处将就**。
M113 之后它返回真正的 `字节`，本探针的 `存口令` 改成
`"盐 " + 编码.十六进制编码(盐)`（`.txt` 是文本文件，盐只能存成十六进制才写得进去），
`口令摘要(口令, 盐, …)` 拿的是**原始字节**。参考实现同步改成 `secrets.token_bytes`。

所以 M113 交付后台账仍是 **5 条**。

## 顺带撞到的（**不进台账**）

写这个工具时还撞到两件事，都**不属于「标准库缺什么」**：

1. **真正的对称加密没有、短期也不打算有**。备份箱想加口令保护，`加密` 里
   没有任何「能还原」的算法（`摘要` / `HMAC` / `口令摘要` 都是单向的）。
   自研 AES + 模式 + 填充 + 认证是一大坨容易写错的活，**0.2.x 明确不做**；
   真要加密归档，现在只能 `系统.执行` 调 `openssl`。记在这里备查。
2. **`文本.按行拆分` 是模块函数，不是方法**。`令 行 = 文本.按行拆分(s)` 里
   那个 `文本` 若是**内建** `文本(...)`（比如同一个文件里又 `导入 文本 为 文本库`
   做了别名导入），就会报「「文本」没有方法「按行拆分」」—— 报错本身很清楚，
   但第一次撞上会愣一下：是「别名导入」和「内建函数」在这里碰了头。

## 用到的语言特性

- `日期`（**加月** / **加年** / **解析ISO** + 今天 / 减天数 / 相差天数 / 早于）
- `加密`（**HMAC** / **口令摘要** / **安全随机字节** + 摘要）
- `压缩`（打包 zip / **压缩文件** / **解压文件**）
- `路径`（按模式找 / 递归列出 / 连接 / 大小 / 文件名）、`文件`、`文本`（别名导入）
- f-string 插值、字符串切片（`名[3:13]` 从归档名里取日期）

## 为什么值得有一份「Python 参考实现」

`参考实现.py` 只用 Python 标准库（`datetime` / `hashlib` / `hmac` / `secrets` /
`gzip` / `zipfile`）做同一件事，**输出与 `备份.jsh` 逐行相同**。两相对照就知道
「这件事本来该多短」—— 差出来的那点，就是基石还没长出来的部分（现在只剩
「单取一份」那一条）。
