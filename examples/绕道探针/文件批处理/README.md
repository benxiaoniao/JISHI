# 文件批处理探针

状态：已毕业（M118 起绕道为 0）

「把一个堆满下载文件的目录整理归档」：按模式找出报告 → 批量改名搬到 `归档/`
→ 原子写索引 → 暂存进临时目录 → 打包 → 日志压成 `.gz` → 递归删临时目录 →
复制一份异地副本 → 自动打开索引。

这是 **M108「文件批处理 + 系统」**立起来的量尺（M109 又消掉它一条）：只用手上的
标准库尽力写，写不顺手的地方就是缺口。**一开始它有 6 条绕道**（按模式找 /
原子写 / 临时目录 / 递归删除 / 系统.打开 / 压 .gz），**M108 消掉 5 条、M109 又
消掉第 6 条**，现在只剩下面「异地副本」这一条 —— 那是**复制目录树**的事。

## 用法

```bash
cd "examples/绕道探针/文件批处理"    # 在探针目录里跑，输出写当前目录
jishi 整理.jsh

# 想让它跑完自动打开索引，先设个开关（无图形界面的环境别开）
整理_自动打开=1 jishi 整理.jsh      # Windows: set 整理_自动打开=1
```

`样本/` 是准备好的输入：三个 `报告*.md`（其中 `旧报告.md` **不带**「报告」前缀，
用来验证模式匹配只挑对的）、一个 csv、两个 log、一个 `说明.txt`。
跑完在 `归档/` 里能看到改好名的报告、`索引.md`、`报告.zip`、`日志.gz`，
以及一份 `异地副本/`。

📌 **M118 把最后一条（R207）也消掉了** —— 于是它不再是量尺，而是
「新能力怎么用」的示范：`文件.复制目录(源, 目标)` 一行搬整棵树。

## 用到的语言特性

- `路径`（**按模式找** / **临时目录** / **递归删除** + 连接 / 父目录 / 文件名 / 大小）
- `文件`（**原子写** + 创建目录 / 复制 / 读文本 / 写文本）
- `压缩`（打包 zip + **压缩文件** gz）、`系统`（**打开** + 环境变量）
- 别名导入（`导入 文本 为 文本库`——模块「文本」会遮蔽内建 `文本(...)`）
- f-string 插值、字符串拼接

## 为什么值得有一份「Python 参考实现」

`参考实现.py` 只用 Python 标准库（`glob` / `os.replace` / `tempfile` /
`shutil` / `webbrowser`），做同一件事。两相对照就知道「这件事本来该多短」
—— 差出来的那点，就是基石还没长出来的部分（现在只剩 gzip 那一条）。
