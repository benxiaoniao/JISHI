# 基石（jishi）

一门简单易用的**中文编程语言**。

`如果`、`遍历`、`函数`、`返回` 这些词**本身就是关键字** ——
你写下的和你脑子里想说的，是同一句话，**中间少一层英译**。

> **技术栈声明（公开透明）**
> - **正式实现只有两套**：**Rust**（前端 + 字节码 VM + 完整宿主，`rust/` + `frontend/`）
>   与 **C**（`cvm/`，自研 C 栈式虚拟机，纯计算场景提速最高约 40x）。
>   发行版 = **cargo 单二进制**，运行时**不需要 Python**。
> - ⚠️ **Python 与 Node 那两套实现已退役**（2026-10-08，R8.4b-2）：挪到 `oracle/`
>   （`oracle/jishi` = Python 实现、`oracle/node` = Node 宿主），
>   **不再随发行版分发、不再提供安装入口**，只作两件事——
>   ① 「多个执行器逐字节一致」这条纪律的**判据基准**；② 改语言的人的参考实现。
> - 执行器现有**四个**：**树遍历参考执行器**（Rust）/ **Rust 字节码 VM** /
>   **C 字节码 VM** / **Python 字节码 VM**（判据基准）。
>   Rust 侧另有一份 `core/`（pyo3 扩展，`JISHI_FRONTEND=rust` 时给 Python 前端用）—— 它也在 `oracle/` 那条判据链里。
> - ⚠️ **C VM 的去留已实测拍板（2026-10-04）：保留**。长任务（300 万次整数循环）
>   实测 **C VM 净 489 ms vs Rust VM 净 649 ms**，且 Rust VM 每次还要付约 100 ms
>   进程启动 —— 两者是**互补**（进程内快执行器 vs 不依赖 Python 的宿主），不是替代
> - **标准库有两份对等实现**：Rust 原生 25 模块（发行版走这份）+ Python 薄封装（判据基准）
> - **在线试玩页跑的就是上面这套引擎**（R8.1/R8.2）：Rust 前端 + 字节码 VM +
>   原生标准库编成 `wasm32-unknown-unknown`，**裸 C ABI + 手写 JS 胶水**，
>   没有引入 `wasm-bindgen`；浏览器里**不再另跑一份 Python 实现**
> - 不 fork、不 patch CPython，也不宣称"完全自主"，以上技术栈如实标注
>
> 已是一条「拿到就能写」的完整通用语言：模块系统、面向对象、异常、包管理雏形、
> AI 原生工具链（语言卡 / 结构化报错 / 评测集）、沙箱 + MCP 集成。
> 定位不是教学玩具，长期目标是可维护的开源项目。

## 安装

**三种装法，都是「自带运行时」，不用先装 Python。**

**Windows** —— 从[下载页](https://基石.cn/download.html)取
`jishi-<版本>-windows-x64-setup.exe`，双击安装即可
（用户级安装、免管理员；简体中文向导，含开始菜单快捷方式、可选加入 PATH、
标准卸载程序）。也有免安装的 `jishi-<版本>-windows-x64.zip`。

**Linux（x64）/ macOS（Apple 芯片 arm64）** —— 下载对应压缩包，
解压后运行 `install.sh`：

```bash
tar -xzf jishi-<版本>-linux-x64.tar.gz
cd jishi-<版本>-linux-x64 && bash install.sh
```

> ⚠️ macOS **目前只有 arm64 版**（没有 Intel / x64 版）。

**从源码构建** —— 给要改语言本身的人。**这不是安装方式**：Python 那套实现已退役，
**不再提供 `pip install` 入口**（`[project.scripts]` 已清空）。正式实现是 Rust，
构建只要 cargo：

```bash
git clone https://github.com/benxiaoniao/JISHI.git
cd JISHI/rust && cargo build --release    # 产出 rust/target/release/jishi-rs
```

⚠️ **这条路要连 GitHub，大陆可能很慢甚至超时**（实测 `git fetch` 会整段超时）。
能用安装程序就别走这条。

> **Python 那套实现**（`oracle/jishi/`）只作**判据基准**与**参考实现** ——
> 不分发、无安装入口；在源码里跑它走 `python -m oracle.jishi.cli`。

**VS Code 扩展**（可选）：扩展市场装 `jishi-lang.vscode-jishi`，有语法高亮、
补全、跳转与调试器（断点 / 单步 / 看变量）。⚠️ **扩展不自带运行时** ——
要先按上面任意一种把 `jishi` 命令装好，它才跑得起来。

装完先跑一次自检，它会顺手告诉你包索引通不通：

```bash
jishi 医生
```

**安装包在[本站下载](https://基石.cn/download.html)** —— 托管在自己的服务器上，
大陆直连可用（不必翻 GitHub）。那一页还有 **逐版本的升级说明**（每个版本改了什么）
与 `SHA256SUMS` 校验和。同一份文件也在
[GitHub Releases](https://github.com/benxiaoniao/JISHI/releases) 上，**逐字节相同**。

> **没有 `pip install jishi` 这条命令**：基石**不发布到 PyPI**。
> 包管理走自己的链路 —— `jishi 安装 <包>`（M49 已落地）：
> 索引与发行包托管在自己的服务器 <https://基石.cn/> 上（**大陆直连**，
> 实测 0.11 秒），GitHub 那份留作**备用源**；两个源**按优先级依次尝试**，
> 第一个通了就用它。索引格式与打包流程见 `docs/语言规格.md`，
> wheel 构建细节见 `tools/build_wheel.py`。

## 快速上手

```bash
# 运行一个 .jsh 文件
jishi examples/01_猜数字.jsh

# 交互式 REPL
jishi -i

# 查看 AST（调试用）
jishi examples/01_猜数字.jsh --ast
```

第一个程序 `你好.jsh`：

```
# 你好，基石
打印("你好，世界！")
令 名字 = 输入("你叫什么名字？")
打印("欢迎你，", 名字)
```

## 语言示例

```
# 猜数字小游戏（判断/循环/输入）
导入 随机
令 答案 = 随机.随机整数(1, 100)
循环 10 次：
    令 猜测 = 整数(输入("猜一个 1-100 的数："))
    如果 猜测 < 答案：
        打印("太小了")
    否则如果 猜测 > 答案：
        打印("太大了")
    否则：
        打印("猜对了！")
        中断
```

```
# 异常处理（M5a：尝试/捕获/最终/抛出）
函数 折扣价(原价, 折扣):
    如果 折扣 <= 0 或 折扣 > 1:
        抛出 值错误("折扣必须在 0 到 1 之间")
    返回 原价 * 折扣

尝试:
    打印(折扣价(100, 2))
捕获 值错误 为 e:          # 异常对象可读 e.消息 / e.类型
    打印("出错了：", e.消息)
```

```
# 面向对象（M5b：类/继承/新建）
类 动物:
    函数 初始化(自身, 名字):      # 「初始化」是构造方法
        自身.名字 = 名字           # 「自身」是实例本身
    函数 叫(自身):
        打印(自身.名字, "在叫")

类 猫 继承 动物:
    函数 叫(自身):                 # 覆盖基类方法
        打印(自身.名字, "喵喵")

令 咪咪 = 新建 猫("咪咪")
咪咪.叫()
```

## 已经能做什么

- **语法**：变量、算术/比较/逻辑、链式比较（`60 < 分数 <= 90`）、
  如果/否则如果/否则、遍历、循环 N 次、当、中断/继续、函数、导入、列表/字典
- **表达力（M7）**：多赋值解包（`令 a, b = [1, 2]`、`a, b = b, a`）、
  默认参数（`函数 f(a, b = 10)`）、列表/字典推导式
  （`[x*2 遍历 x 在 列表 如果 x>2]`）、文本插值（`` `你好 {名字}，今年 {年龄} 岁` ``）
- **异常处理（M5a）**：`尝试`/`捕获 类型 为 e`/`最终`/`抛出 值`；
  9 种内建错误类型（`值错误` 等）可抛可抓，基类抓子类，`e.消息`/`e.类型` 可读
- **面向对象（M5b）**：`类` 定义方法、`继承` 复用与覆盖、`新建` 实例化、
  自动构造（`初始化`）、实例字段、绑定方法（`自身`）
- **内建函数**：打印、输入、整数/小数/文本、精确、**序数/字符**、长度、范围、
  最大、最小、总和、类型、反转、打开
- **对象方法**：
  - 列表：追加 / 插入 / 移除 / 弹出 / 排序 / 反转 / 清空 / 索引 / 计数 / 包含 /
    映射 / 过滤 / 排序按 / 归约
  - 字典：获取 / 键 / 值 / 包含 / 更新 / 弹出 / 清空
  - 文本：拆分 / 替换 / 查找 / 大写 / 小写 / 去空白 / 开头是 / 结尾是 / 包含 / 转整数 / 转小数
  - 集合：添加 / 移除 / 丢弃 / 包含 / 并集 / 交集 / 差集 / 对称差 / 清空 / 转列表 / 复制
  - 文件：读 / 读行 / 读所有行 / 写 / 写行 / 关闭 / 刷新 / 位置 / 定位
  - 精确小数：舍入 / 绝对值 / 转文本
- **语言功能（M23–M34）**：成员测试 `在`/`不在`、同一性 `是`/`不是`、
  `超()` 调父类方法、类变量、`断言`、`是实例`；
  集合（有序去重 + 交并差）、迭代协议、切片赋值、可选类型标注、
  匿名函数、数据流水线（映射/过滤/排序按/归约）；
  变长参数 `*参数`/`**选项`、星号解包 `令 甲, *余 = …`；
  上下文管理器 `用 … 为`、文件对象（`打开`）、自定义对象打印（`文本()` 方法）、
  精确小数 `精确(…)`；
  **值的显示统一**（空/真/假 中文；打印·文本·插值·REPL 回显一处实现）；

## 架构与数据流

```
源码 → tokenizer → parser → AST ──┬─→ Interpreter（树遍历，默认执行器）
                                  └─→ 编译器 → 字节码 ──┬─→ Python VM
                                                        └─→ C VM（jsvm.dll）
```

- **前端正在换 Rust（R 线）**：`tokenize()`（R2）与 `parse_source()`（R3）都已可以
  在 Python 与 Rust 之间切换（`JISHI_FRONTEND=rust`，**默认仍是 Python**）。
  换了之后**产物逐项一致**（88 个语料 + 2 万/5 万组随机对拍）：分词纯核心
  **7.05 倍**、端到端 **3.72 倍**；语法纯核心 **5.64 倍**、端到端 **3.04 倍**。
  ⚠️ 端到端有 **4.23 / 4.73 倍的天花板**：前端各阶段在 R2–R5 期间仍要把产物
  交回 Python，而「造 Python 对象」本身就有地板 —— 那才是 R5/R8 才兑现的收益。

- 三个执行器（树遍历 / Python VM / C VM）共用 `jishi/runtime.py` 的语义，
  `tests/test_cvm.py` 对拍保证「换执行器不改变任何可观察行为」
  （stdout 与报错逐字节一致）。
- 默认仍走树遍历；`jishi/vm.py` / `jishi/cvm_bind.run_source_c` 可切换。
  性能：C VM **纯算术 11–48x**、**列表构建与遍历 14x 上下**、**字典写入 6x 上下**；
  **文本拼接约 3x、文本比较约 12x**（M47：文本改成 **C 侧原生字符串**，
  拼接与比较不再回调宿主）；**浮点 / 布尔遍历 6x 上下**。
  ⚠️ **宿主回调是 C VM 的已知瓶颈**：每次内建 / 方法 / 标准库调用固定约 **2.4µs**
  （C↔Python 的 FFI 往返，**与被调函数做什么无关**），所以「内建调用密集」只有
  0.91x。**要提速就得减少回调次数**，而不是把回调内部写得更快。
  **文本下标 / 切片**（要回调宿主执行切片协议）、**文本遍历 / 文本列表遍历**
  （循环体每元素至少一次回调）、**字典查找**（读没法合并）都受这条制约。
  这些边界都逐字记录在 `tools/benchmark.py`，是**已知边界、不是待修缺陷**。
- **AI 原生能力**（M8/M9）架在 AST 与报错之上：`jishi/ai.py` 从
  tokenizer/parser/runtime/stdlib 动态收集元数据，产出语言卡、语言规格、
  JSON 结构化报错；`jishi/mcp_server.py` 把执行能力暴露给任意 MCP 宿主。

## 环境要求

- **使用**：从 <https://基石.cn/download.html> 下载对应平台的发行包（Windows 安装程序 /
  Linux / macOS 压缩包）—— 发行版是 **cargo 单二进制**，**不用先装 Python**，

- **Python ≥3.13**：**只用于构建脚本与测试套件**（生成语言卡、构建站点、
  跑判据对拍），**不是运行时依赖**。运行时零第三方依赖；测试用 pytest，

  的 AST 扫描兜底。）
- Windows 注意：venv 可执行文件在 `Scripts/` 而非 `bin/`。

## 关键技术决策（详见 docs/设计决策.md）

- **D1 技术栈透明**：Python 前端 + C 内核 + Python 生态桥接，不 fork/patch CPython
- **D2 分词消歧**：关键字粘连检查只针对**多字关键字**（如果/循环/导入…），
  单字关键字（类/当/真/空/非/令）不做前缀检查，否则 `类型`/`当时`/`空间` 等日常词全被误伤。
- **D3 全角标点**：字符串与注释外做一对一归一化（`＝`→`=` 等）；全角空格 U+3000 在缩进中报错。
- **D4 执行模型**：树遍历 → 字节码 + C VM（M4），语法不变，对拍测试保证一致。
- **D5 标准库**：中文 API 是薄壳，绝不重造轮子，真实价值来自 Python 生态。
- **D7 对象方法分派**：方法表按类型分派返回闭包，列表方法原地修改、文本方法返回新值。
- **D8 REPL**：顶层表达式非空回显（真/假/空中文化）；空行强制结束多行块。
- **D11 异常对象模型（M5a）**：异常即 `JishiError` 实例，`e.消息`/`e.类型` 可读；
  捕获条件按类型名匹配，用 isinstance 判断（基类抓子类）。
- **D12 语法用中文助词（M5a）**：`捕获 值错误 为 e:`、`继承 基类:` 用「为/继承」
  等助词连接，不用冒号嵌套的类 Python 写法，读起来更像自然语言。

## 已踩过的坑（避免重踩）

1. `re.fullmatch` 对 `[...]` 单字符类多字符永远 False，要用 `[...]+` 运行正则。
2. dataclass 继承字段顺序 → 全部 `@dataclass(kw_only=True)`。
3. 全角引号需配对表（`“` 配 `”`），不是同字符闭合。
4. 块语句以 DEDENT 结束，parser 主循环不能要求 NEWLINE。
5. `与/或` 右操作数要用 `parse_expr(prec+1)` 而非 `parse_unary()`，否则比较运算符逃逸。
6. `dump_ast` 用 `vars()` 前先判类型（tuple/list 无 `__dict__`）。
7. Windows venv 路径 `Scripts/` 不是 `bin/`。
8. 尾随逗号：列表/字典/调用参数/函数参数四处循环都要支持（M2 已修）。
9. `数学.幂` 用 `math.pow` 返回 float，整数期望 int → 用 `**` 运算符。
10. `导入 文本` 会遮蔽内建 `文本()` 转换函数（与 Python 导入遮蔽一致，文档已注明）。
11. 调用括号内的 `名字 = 值` 一律按关键字参数处理（parser 调用上下文无赋值语义）。
12. `_lookup` 查英文 True/False/None 的提示要在"你是不是想写"建议**之前**抛出，
    否则编辑距离建议会给出误导性结果。
13. 三执行器共享 runtime 语义，但异常穿透调用栈的「重入边界」必须一致
    （vm.py 的 stop_at / C VM 的 stop_depth），否则类方法里 `抛出` 会被错误接住。
14. `非` 的优先级必须**低于比较运算**（M23 修正）。写成一元（最紧）会让
    `非 年龄 >= 18` 变成 `(非 年龄) >= 18` 恒为假——**静默给错答案**，
    项目教程自己就踩过。现按 Python `not` 语义：`非` 吃掉右边的比较表达式，
    吃不掉 `与/或`。
15. 新增比较运算码（`在`/`不在`/`是`/`不是`）要放在 **6–9**，不能占用 0–5：
    0–5 是 C VM 的 `compare_fast` 快路径，6 以上自动回落宿主回调
    `host->compare`——这是「加语义比较运算符零 C 改动」的前提（见 opcodes.CmpOp）。
16. C VM 里同一个函数每次跨边界都会新建 `CvmFunction` 包装，直接按 `id()`
    判断同一性会与另两个执行器结果相反（`f 是 g`）。修法是按 `JVal.v.u`
    （底层 `JsFunc*` 指针）缓存包装（见 `cvm_bind.CvmHost._func_cache`）。
17. 加比较类关键字（`不在`/`不是`）必须同时加进 tokenizer 的
    `_GLUE_CHECK_SKIP`：它们本身是常用词前缀，否则 `不在列表`、`不是我`
    这类正常变量名会被「关键字粘连」检查误报。

## 设计原则

1. **像 Python 一样简洁**：缩进划分代码块，语法零冗余。
2. **中文是母语**：报错信息全中文，精确到行列，附"你是不是想写…"修正建议。
3. **生态即生命**：绝不重造标准库，薄封装 Python 生态。
4. **透明不吹牛**：技术栈如实标注，走长期演进路线。
