# 自测运行器的豁免表（`tools/自测.jsh` 读这个文件）
#
# 格式：每行 `被测标签 | 用例名 | 原因`，`#` 开头是注释。
#   被测标签 = 「被测」那个程序的文件名（`jishi-rs.exe` → `jishi-rs`，`python.exe` → `python`）
#
# 🔴 规矩（`AGENTS.md` §1「豁免必须显式、可复核、会过期报红」）：
#   1. **只登记「真实的引擎能力边界」，不登记 bug**。是 bug 就修，别往这儿塞。
#   2. **必须写原因**：没写原因的豁免会被运行器直接报错（没有原因的豁免等于没有）。
#   3. **会过期报红**：被豁免的用例哪天**过了**，运行器会红着喊你删掉这一行 ——
#      留着它只会遮住这条用例。同理，这里的用例名在目录里找不到也会红。
#   4. 加豁免不是「让它变绿」：汇总行会单独打 `豁免 N`，**它不算通过**。
#
# 现在只有 1 条，而且是有明确说法的边界：

jishi-rs | 13_从python导入.jsh | Rust 引擎不支持「从 python / 本地包」导入（那条 .err 记的是 Python 参考实现的说法：「Python 里没有模块「量子计算」」）。这是 Rust 侧宣称过的边界，不是本版新出的 bug。
